## 4. 收录规则

- 当前只收录卡牌类型为“妖怪”的条目。
- `CYS_007`“福兮祸兮”、`CYS_017`“烈日当空”和 `CYS_020`“日轮高悬”不是妖怪牌，不建立妖怪档案。
- 妖怪 ID 与卡牌 ID 分离；同一妖怪未来可以关联多张卡牌。
- 多形态妖怪使用“父级妖怪 ID + `_序号`”记录运行时形态；子形态不因此获得独立的可入牌组卡牌 ID。
- 本批设定为 AI 协助生成的第一轮样本，统一保持 C3，待人工逐只审核。
- 当前收录的澄曜区与澜桥区常规生物妖怪档案统一标为兽灵；名称或外形近似器物的个体也必须以自然演化谱系解释。赞助商卡池已采用机械造物：规则上属于妖怪、自带“机械”，不归为兽灵；其制造来源档案另行建档。物灵、恶灵留待后续卡池采用时建档。
- 档案不设置“常见用途”字段。社会关系只记录接触、共居、驯养、冲突、保护与传说，不要求每个物种服务人类社会。
- 人工确认后，应在对应档案的变更记录中写明确认内容，再提升正史等级。
