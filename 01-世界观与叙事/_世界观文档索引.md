## 3. 文件职责

| 文件类型 | 负责内容 | 不负责内容 |
|---|---|---|
| 正史规则 | 正史等级、冲突优先级、不可擅改项 | 具体剧情扩写 |
| 世界观总览 | 一句话定位、核心支柱、世界运转边界 | 单区全部细节 |
| 地理层级规则 | 世界级地区、子地区、地方单元及 ID | 现实行政体系模拟 |
| 九川地区总览 | 六区完整性、比较优势、跨区网络与九川级制度 | 取代六区档案 |
| 六区档案 | 区域生态、产业、视觉、组织、矛盾和玩法 | 修改 C0/C1 规则 |
| 妖怪档案 | 妖怪物种、生态、社会关系、玩法来源和卡图指引 | 取代卡牌战斗数值源 |
| 综合素材稿 | 保留妖怪样例、剧情钩子和早期制度构想 | 在冲突时覆盖正式规则 |

## 4. 当前改造原则

- 保留既有六区的核心定位、地方单元、代表组织、剧情钩子和卡牌生产方向。
- 只对地理层级、正式术语、组织名称冲突和 Unity ID 映射做定点统一。
- 新增内容默认保持 C2 或 C3；只有明确写入 C0/C1 文件的既有指导规则才按相应等级使用。
- 无法从现有资料判断的问题进入待确认清单，不由 AI 自行补全。
