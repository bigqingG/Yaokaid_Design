# 世界观变更日志

## 2026-09-27（终版核定）｜澄曜区地图空间结构修订

### 修订背景

- 依据《澄曜区地图新增设定_本地AI同步说明》，以新地图空间关系为准，修订 v1.5 中与之冲突的设定；澄曜区档案升级至 1.6。

### 调整

- 三镇方位核定：静湖镇改定为区西北、澄湖镇改定为东北、雾湖镇改定为西南（玩家初始地不变）；撤销“南缘湖盆三湖串珠、由南向北成链”的旧描述。
- 燃栖城核定为位于燃栖城郊带内部的独立城市，不属于澄曜主市区，与主市区主要以动车连接；燃栖城管辖整个燃栖城郊带，实际建成区小于行政管辖范围。
- 燃栖城郊带改定为红沙、红色岩石、红色裸岩广布的生态—半荒漠地带，沙化明显；澄青河支流穿行并形成条带状绿洲，不再以“绿色郊区”为基调。
- 区分**红谷生态区**（城郊带内大型生态区域，占城郊带很大一部分）与**红谷**（燃栖城南方、两侧红色巨岩夹成的具体谷地及谷底道路）；原“红谷生态保护区”统一更名为红谷生态区，建议 ID 调整为 `AREA_HONGGU_ECO_REGION`。
- 红谷道路在历史上长期是青棠区（位于澄曜西侧）进入澄曜城区的主要甚至唯一通道；现代动车与公路建成后不再只有该通道，其现代道路功能待确认。
- 澄青河流向改定：从静湖镇与雾湖镇之间穿过，向区内延伸并形成大量支流，部分支流进入城郊带造就绿洲，干流最终流向主市区南侧、从澄曜港口入海；撤销“穿城郊带进入青棠湖群、在澜桥南侧汇入分流”的旧流向。
- 新增澄曜港口地方单元（南侧内凹港湾、河口，`AREA_CHENGYAO_HARBOR`），港口正式名称待确认。
- 动车系统核定：静湖（经燃栖城）、雾湖、澄湖三方向线路最终汇集于主市区同一个**市区中心站**（`LOC_CHENGYAO_CENTRAL_STATION`），三镇与燃栖城均设站；撤销“仅澄湖、燃栖设站”的旧表述。
- 新增地图美术与 UI 规范：二次元卡通非写实地图、城镇为悬浮可交互节点、地形与节点 Sprite 拆分、黑幕按“雾湖 → 静湖 → 燃栖 → 中心站与澄湖 → 全区”顺序解锁。
- 晋级阶梯同步调整：见习协行者 → 协行者（雾湖印）→ 红谷协行者（静湖印、红谷火印）→ 巡曜协行者（澄湖印、进入主市区）→ 御灵师。

### 同步文件

- 六区地方单元索引（1.2）、九川地区总览（1.3）、青棠区档案（1.4）、地区特色与基础世界观（1.4）、玩家图鉴站 app.js。

### 保留与边界

- 协行者/御灵师称谓定义、御灵大考框架、赤轨俱乐部、扬子江光学电力公司及火/金玩法基调不变。
- 人口、行政级别、城镇归属、燃栖城产业与历史、生态区成立年份与机构、种群清单、河流长度、港口与线路正式名称、站间距、支流名称、地质成因、红谷道路现代功能等均按同步要求留待人工确认，不擅自补完。

## 2026-09-27｜澄曜区四镇、交通体系与协行者—御灵师晋级体系

### 新增

- 澄曜区新增三座湖滨城镇：雾湖镇（`AREA_WUHU_TOWN`，玩家默认出生与新手教学地）、静湖镇（`AREA_JINGHU_TOWN`）、澄湖镇（`AREA_CHENGHU_TOWN`）；另于燃栖城郊带南缘新增城镇燃栖城（`AREA_RANQI_CITY`）。四镇均为澄曜区下辖的普通地方单元，不另设城镇群等集合设定。
- 四镇各设一处挑战俱乐部：晓雾俱乐部、明镜俱乐部、澄光俱乐部、燃栖俱乐部，承担新人登记、教学对局与晋阶考核；燃栖俱乐部与赤轨俱乐部保持青训合作。
- 四镇各辖一处保护区：雾湖湿地保护区、静湖保护区、澄湖保护区、红谷生态保护区（补全既有地名的建议 ID `AREA_HONGGU_ECO_RESERVE`），按危险度分阶，对应保护区 2D 冒险玩法。
- 新增城镇交通体系：湖盆线大巴（开局可用、站站停靠）、澄曜城际动车（快速、实名、需卡牌携行执照，停澄湖镇与燃栖城等站）、三湖水上船班，并规定妖怪携行、天气延误与车次切换规则。
- 新增称号与晋级体系：新手称“协行者”（驯服妖怪对战并修习法术），资深者称“御灵师”（通过区级御灵大考）；晋级阶梯为见习协行者 → 正式协行者 → 三湖协行者 → 巡曜协行者 → 御灵师，以俱乐部挑战、湖印收集与保护区实战考核驱动。

### 调整

- 明确燃栖城坐落于燃栖城郊带南缘，城郊带是南部各镇进入曜心城区的过渡地带；澄青河源头描述补充三湖串珠结构。
- 澄曜区档案由 1.4 升级至 1.5，新增城镇、交通、称号章节，章节顺序后移，并同步扩充玩法映射、剧情钩子、卡牌生产方向与 Unity 数据建议。
- 六区地方单元索引由 1.0 升级至 1.1，澄曜区新增 8 个地方单元及建议 ID。
- 同步更新玩家图鉴站澄曜区可探索地方单元列表。

### 保留与边界

- 澄曜区现代新能源都市定位、火/金元素倾向、赤轨俱乐部与扬子江光学电力公司等既有设定不变。
- 协行者/御灵师认证当前为澄曜区地方制度（C2），九川统一认证、跨区互认、御灵大考授权机构与线路命名等待确认事项不作自动补全。

## 2026-08-30｜九川主干水系与澜桥地名修订

### 新增

- 将砚澜江与澄青河确认为九川水系的两条主干江河；其余七条水系保留为后续可展开的支流、旧河道、灌溉河和潮汐水道。
- 明确砚澜江由砚岭山地流经沃衡平原与水衡渠网，在澜桥下游分汊后汇入东部海域；澄青河由澄曜南缘流经燃栖城郊带和青棠湖群，最终汇入澜桥南侧下游分流。
- 明确跨区江河等自然网络不构成新的地理或行政层级。

### 调整

- 将澜桥区地方单元“湿码洲”更名为“汀泊洲”，以避开网络语境中的不良谐音；对应建议 ID 从 `AREA_WET_DOCK_ISLE` 调整为 `AREA_TINGBO_ISLE`。
- 同步更新九川总览、地理层级规则、六区地方单元索引以及砚岭、沃衡、澄曜、青棠、澜桥区档案。

## 2026-07-25｜澄曜区宜居性与视觉特色修订

### 修订目标

将澄曜区从“反光幕墙、高亮屏幕与热岛共同构成的光污染都市”调整为具备正常宜居底线的现代新能源都市区；保留职业竞技、商业媒体和火/金玩法优势。

### 调整

- 确认澄曜位于九川及该国南部、靠近世界赤道一侧的低纬城市带，气候改为长夏、湿热、强日照与短时强降雨。
- “现代新能源都市区”继续作为社会定位；南部低纬属于区位信息，不再并入社会定位、气质定位或名称式介绍。
- 将“太阳能幕墙”明确为建筑光伏一体化设施，功能是发电、围护与遮阳，不承担反射照明。
- 新增建筑眩光、户外显示、高架交通、公共遮阴、绿地和雨洪管理规则。
- 重写曜心城区、赤轨新城、镜幕商环、燃栖城郊带与曜南竞技公园的建成环境，使住宅、学校、社区服务和日常公共空间进入城市画面。
- 删除以大量反光、高亮广告和常态光污染作为澄曜特色的表述，并同步调整相关妖怪生态与卡图指引。
- 将主要剧情冲突重新锚定在赛事商业化、公共能源优先级和明确的违规责任，而不是把恶劣环境写成城市默认状态。

### 保留

- 澄曜区作为现代新能源、职业竞技、商业媒体和品牌经济优势区的定位。
- 火、金元素倾向与快攻、爆发、连击、过载后付出代价的玩法语法。
- 赤轨俱乐部、扬子江光学电力公司及既有地方单元名称和 Unity ID。
