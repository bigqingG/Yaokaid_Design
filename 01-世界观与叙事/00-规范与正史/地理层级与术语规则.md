# 世界地理层级与术语规则

> 文档版本：1.1  
> 文档状态：正式规则  
> 正史等级：C1 已确认指导规范

## 1. 唯一地理结构

```text
第一层：世界级地区
第二层：子地区（正式简称“区”）
第三层：地方单元
```

套入当前设定：

```text
九川地区（WR_JIUCHUAN）
├── 澄曜区（REG_CHENGYAO）
├── 澜桥区（REG_LANQIAO）
├── 青棠区（REG_QINGTANG）
├── 砚岭区（REG_YANLING）
├── 霜港区（REG_SHUANGANG）
└── 沃衡区（REG_WOHENG）
```

具体地点可以从属于地方单元，但不构成第四层世界观地理等级。

跨越多个子地区的江河、山脉、海湾、交通走廊和生态迁徙带属于地图与自然网络对象，不构成新的地理层级。它们可以关联多个 `SubRegionSO` 或 `LocalAreaSO`，但不应被误写为行政区、子地区或地方单元的上级。

## 2. 术语定义

### 世界级地区

世界范围内最高级的地理与社会共同体。当前代表是九川地区。九川在叙事职能上相当于完整社会主体，但正式公开称谓仍为“地区”。

正确写法：

- 九川地区职业联赛；
- 九川地区卡牌技术标准；
- 九川各区代表赛；
- 九川之外的其他世界级地区。

避免写法：

- 九川国；
- 九川共和国；
- 九川省；
- 九川联邦；
- 九川地区下的国家。

### 子地区（区）

世界级地区内部的大型综合区域。一个区可以同时包含核心城区、县镇、村落、产业带、生态区、港口、岛群、高校、研究区和竞技设施。

“区”不是现实城市中的普通市辖区，也不能被写成单一城市或单一元素景区。

### 地方单元

区下的具体地理与内容生产单位，包括：

- 中心城区、城市、县、镇、村和街区；
- 港区、产业带、农业带和大型基础设施；
- 岛群、湿地、山谷和其他生态区域；
- 研究区、竞技公园和具体地标。

县、镇、村可以继续拥有内部地点，但这些地点不形成新的地理层级。

## 3. 命名规则

| 层级 | 推荐格式 | 示例 |
|---|---|---|
| 世界级地区 | 两个汉字 + 地区 | 九川地区 |
| 子地区 | 两个汉字 + 区 | 澄曜区、霜港区 |
| 地方单元 | 按真实功能命名 | 苍原县、曜心城区、寒坞船造带 |

不得为了格式统一，把所有地方单元都命名为“××区”。

## 4. ID 与 Unity 映射

| 前缀 | 对象 | Unity 数据 |
|---|---|---|
| `WR_` | 世界级地区 | `WorldRegionSO` |
| `REG_` | 子地区 | `SubRegionSO` |
| `AREA_` | 地方单元 | `LocalAreaSO` |
| `LOC_` | 具体场景或地标 | 资源/场景标识，不是第四级地区 |

最小数据关系：

```text
WorldRegionSO
└── SubRegionSO
    └── LocalAreaSO
```

卡牌来源建议分别引用：

```text
originWorldRegion
originSubRegion
originLocalArea
```

## 5. 新设定归属检查

每个新地点至少回答：

1. 属于哪个世界级地区；
2. 属于哪个子地区；
3. 自身是地方单元还是具体地点；
4. 能支持哪些妖怪、卡牌、剧情或视觉场景；
5. 为什么属于本项目，而不是仅仅提供一个新地名。
