# 九川地区·澄曜区设定档案

> 文档版本：1.4  
> 正史等级：C2 制作中设定  
> 子地区 ID：`REG_CHENGYAO`  
> 所属世界级地区：九川地区（`WR_JIUCHUAN`）  
> 子地区类型：现代新能源都市区  

> 地理层级说明：澄曜区是九川地区下的第二层子地区，不等同于现实城市中的普通市辖区。区内的核心城区、县域、镇村、产业带、生态区和大型基础设施统一属于第三层地方单元。

> 区域完整性说明：澄曜区拥有独立的食品与能源供应、交通物流、制造商业、教育医疗、媒体文化、公共服务、妖怪管理和竞技体系。新能源、职业竞技与商业媒体是比较优势，不是由澄曜垄断的九川级职能。

## 3. 地理结构与地方单元

### 3.1 曜心城区

澄曜区的行政、商业与文化核心。高层建筑与中层街区混合分布，沿街设置骑楼式遮阴空间、林荫步道和小型公共广场。建筑光伏主要安装在屋顶、站棚、遮阳构件和不透明外墙板上，用于就地发电；临街立面以低反射材料为主。

**主要功能：** 职业联赛主会场、卡牌交易中心、联盟办事处、明星选手与赛事媒体聚集地。
### 3.2 赤轨新城

围绕新型轨道交通、储能设施和企业总部建设的新城区。车站、住宅、学校、社区服务和就业中心混合布局，部分高架区段下方被改造成球场、雨棚市集和连续绿道。

**主要功能：** 赤轨俱乐部总部、扬子江光学电力研发中心、企业训练营和青年技术人员社区。
### 3.3 镜幕商环

“镜幕”是早期影院和赛事转播业留下的历史地名，并不表示建筑普遍采用镜面外墙。今天的商环由商业综合体、媒体中心、剧场、步行街和公共广场组成；大型显示设施集中在场馆与获批商业节点，并受亮度、时段和朝向限制。

**主要功能：** 赞助活动、卡牌新品发布、城市挑战赛、表演赛和选手商业代言。
### 3.4 燃栖城郊带

中心城区与外围生态之间的过渡带，分布能源维护站、旧住宅、仓储设施、低丘绿地、季节性湿地和妖怪巡检路线。

**主要功能：** 基层维护人员生活、低费城市妖怪栖息、能源扩建与社区搬迁剧情。
### 3.5 曜南竞技公园

综合训练、青少年赛事、公开挑战和市民休闲于一体的竞技园区。大型场馆之间保留成片树荫、雨水花园、公共球场和日常开放的慢行环线，非赛期仍是普通市民使用的城市公园。

**主要功能：** 新手教学赛、学院联赛、俱乐部试训、赞助商测试卡和节庆活动。

## 4. 环境、气候与建成空间

### 4.1 区位与气候

- 澄曜位于九川南部，也是该国靠近世界赤道一侧的低纬城市带之一。
- 澄青河发源于本区南缘低丘与季节性湿地，穿过燃栖城郊带后流向青棠；其上游湿地兼具雨洪调蓄、城市生态与妖怪迁徙功能。
- 全年日照资源充足，高温季节较长，空气湿度偏高，常见短时强降雨和季风天气。
- 中心城区存在热岛效应，但其严重程度受街区密度、树冠覆盖、通风廊道和地表材料共同影响，不将“灼热难居”视为城市常态。
- 城郊保留低丘、季节性湿地、农林斑块和连续生态廊道；城市绿化完整存在，但不是澄曜区别于其他地区的唯一特色。

### 4.2 气候适应

- 街道普遍采用行道树、深檐、连廊、可开启遮阳板和透水铺装，为步行与骑行提供连续遮阴。
- 轨道站、学校、医院、体育公园和社区中心设有饮水、避雨与高温时段开放的公共纳凉空间。
- 雨水花园、下沉绿地和调蓄池用于应对短时强降雨，同时构成普通城市妖怪的栖息点。
- 建筑群通过退台、架空层和通风廊道组织盛行风，减少对机械制冷的单一依赖。

### 4.3 建筑光伏与玻璃幕墙规则

- 澄曜所谓“太阳能幕墙”是建筑光伏一体化立面：光伏组件同时承担发电与部分围护、遮阳功能。它不具备、也不允许具备将阳光定向反射至街道的用途。
- 光伏立面优先布置在屋顶、站棚、遮阳板和不透明外墙面；需要采光的部位可使用半透明组件，但必须满足室内采光、隔热、防火、检修和鸟类友好要求。
- 玻璃与光伏工程在审批前必须完成全年反射眩光模拟。面向道路、住宅、学校、医院和公共活动场地的立面采用低反射材料，不得形成持续眩光、聚光热斑或影响交通视线。
- 可转向反射构件仅能用于封闭式能源试验场，并设置失效归零和人工切断机制。把反射光束导向地面、人群或相邻建筑属于明确违法行为。
- 建设、环境与交通管理部门分别负责方案审批、光环境复核和道路安全评估。违规设施可被责令立即停用、限期整改并追究损害责任；赛事项目还会受到场馆许可和联盟资格处罚。

### 4.4 户外显示与高架交通规则

- 户外显示设施集中在竞技场、交通枢纽和少数商业节点，必须自动适应环境亮度；住宅界面、生态廊道和夜间道路禁止使用持续高亮、快速闪烁的内容。
- 大型赛事结束后，外屏按规定时段关闭或转入低亮静态公共信息模式。临时活动若需延长点亮时间，必须单独报批并承担妖怪生态监测。
- 高架轨道只在客流与地形确有需要的区段使用，并受噪声、振动、遮阴和街区连通性评估约束；学校、医院和密集住宅附近优先采用地下、地面或全封闭低噪方案。
- 高架下空间不得成为连续灰色隔离带，应安排照明、排水、绿化、慢行通道或社区设施，并保留足够的横向步行联系。

## 5. 产业与居民生活

### 5.1 核心产业

- 新能源研发、设备制造与并网服务
- 建筑光伏、储能与城市能源管理
- 轨道交通、公共空间与城市维护
- 职业竞技与俱乐部经济
- 赛事媒体、广告和卡牌发行
- 消防、安保与巡检妖怪服务

### 5.2 居民生活

居民重视效率、专业能力和公共信誉。年轻人普遍熟悉职业联赛、俱乐部排名和赞助活动，但日常生活同样由通勤、学校、社区商业、公园活动和家庭关系构成。核心城区与新城公共服务密集，城郊承担部分能源、物流和生态维护功能，由此产生资源分配争议，但不被描写成被城市抛弃的牺牲区。

## 6. 妖怪生态

### 6.1 常见生态类型

- 吸收热量或光能的城市妖怪
- 栖息在轨道、金属设施与能源站附近的妖怪
- 适应建筑遮阴、树冠和夜间常规照明的城市夜行种群
- 用于消防、巡检和安保的工作妖怪
- 受到热岛、暴雨和街区更新影响而改变习性的外围种群

### 6.2 生态与社会议题

- 个别违规赛事照明或临时活动扰乱夜行种群
- 能源与交通扩建可能切断旧有栖息廊道
- 企业驯养种群与野生种群差异扩大
- 竞技训练过度消耗妖怪
- 火元素浓度与人工天气叠加造成城市热风险

### 6.3 设计底线

- 妖怪外形必须先满足生物轮廓与生态逻辑，再叠加元素表现。
- 元素不应被简化成固定颜色、发光或机械装饰。
- 本区代表妖怪不应全部围绕职业竞技；必须保留工作、野生、家庭和地方生态种群。
- 卡牌效果应尽量从行为、产业用途、天气关系或社会处境中产生。

### 6.4 妖怪档案入口

澄曜区第一批妖怪物种档案见[澄曜区妖怪设定索引](../02-妖怪设定/_妖怪设定索引.md#2-澄曜区妖怪)。当前均为 C3 候选设定，卡牌战斗数值仍以卡牌设计文档为准。

## 7. 社会文化

- 本区社会气质以“明亮、快节奏、商业化、竞争激烈”为主，但内部必须保留阶层、城乡和代际差异。
- 本区竞技传统应与产业和居民生活有关，不能只靠俱乐部口号区分。
- 赞助商、俱乐部、公共机构、居民组织与妖怪保护方应拥有不同利益。
- 地方文化应通过节庆、语言习惯、工作流程、建筑和日常关系体现，而不是依赖长篇说明。

## 8. 视觉语言

### 8.1 核心视觉关键词

- 南方强日照下的浅色墙面、暖色遮阳构件与清晰天际线
- 车站光伏顶棚、建筑外遮阳和可见的能源维护结构
- 林荫主路、骑楼式步行空间、雨水花园与普通社区公园
- 高架轨道、地面公交和慢行网络共同构成的立体交通
- 赛事期间出现的旗帜、导视和受控场馆屏幕
- 核心商圈、新城住区、旧社区与城郊生态的连续过渡

### 8.2 禁止倾向

- 全区赛博朋克化
- 所有金元素妖怪机甲化
- 只使用霓虹夜景
- 忽视学校、住宅和基层工作场景
- 把火元素等同于全身燃烧
- 用连续反光玻璃、刺眼光束或全天候巨屏表现“新能源”
- 把高温和商业化写成居民长期忍受污染的城市常态
- 只画高架、写字楼和竞技场，忽略树荫、街道生活与公共服务

### 8.3 卡图构图要求

- 妖怪是画面主体，但背景必须能识别所属区和具体地方。
- 同一区不能让所有卡图使用同一种天气、时间或地标。
- 背景应体现工作、生活、生态或剧情，而不是纯装饰。
- 避免直接生成卡框、文字、数值、Logo 和 UI 元素。

## 9. 代表组织

### 9.1 赤轨俱乐部

商业影响力极强，强调主动进攻、镜头表现和数据化训练。内部存在“竞技成绩优先”与“选手品牌优先”的路线争议。

### 9.2 扬子江光学电力公司

**业务与卡池术语方向：**

- 峰值功率
- 过载
- 并网
- 储能
- 负荷调度
- 热管理
- 光伏阵列
- 建筑光伏一体化
- 低反射封装
- 遮阳调度
- 紧急供电
- 光学巡检
- 削峰填谷

**适合的赞助卡机制：**

- 短期获得高额资源或伤害，之后承担代价
- 连续出牌形成峰值收益
- 储存本回合未使用资源
- 根据场上高费或低费卡调整负荷
- 在过载后进入冷却或修复阶段

赞助商卡池必须同时体现收益、流程、风险和行业限制，不能只做成本区元素法术合集。

## 10. 核心矛盾

### 10.1 表层问题

职业赛事高速扩张，俱乐部、企业与媒体不断提高比赛规模和商业曝光。

### 10.2 深层原因

- 赛事商业价值开始压过竞技与妖怪福利
- 企业掌握训练资源、克隆设备和曝光渠道
- 城郊承担能源扩建的生态成本
- 年轻选手把签约视为唯一上升通道

### 10.3 主线命题

> 当竞技成为一座城市最重要的商品，选手与妖怪还能否决定自己以何种方式被看见？

### 10.4 冲突设计要求

- 不将企业统一写成纯粹反派。
- 不让公共机构只承担说明规则的功能。
- 冲突必须涉及真实利益分配与持续后果。
- 结局应改变人物关系、区级制度、产业安排或妖怪生态中的至少一项。

## 11. 游戏玩法映射

| 世界观内容 | 玩法表达              |
| ----- | ----------------- |
| 能源峰值  | 本回合爆发，之后承担资源或生命代价 |
| 城市快节奏 | 低费连打与连击           |
| 职业曝光  | 打出多张牌后追加收益        |
| 过载设施  | 消耗生命、耐久或下回合资源     |
| 轨道调度  | 快速移动或换位           |
| 城郊维护  | 低费单位离场后提供修复与资源    |

该区的卡组不能只有单一套路，至少应设计：一个主流构筑、一个偏控制或资源的替代构筑，以及一个由玩家探索出的跨区混合方向。

## 12. 剧情钩子

1. 赤轨俱乐部准备签下一名未成年选手，但合同包含其妖怪的长期商业使用权。
2. 一场获批赛事被承办方擅自延长外屏点亮时间，附近夜行妖怪改变迁徙路线；争议焦点是企业是否绕过了既有审批和生态监测。
3. 大型公开赛使用了尚未完全验证的高负荷幻影克隆设备。
4. 城郊旧社区因能源扩建面临搬迁，当地妖怪栖息地也将被清除。
5. 企业内部数据表明赛事期间用电优先级高于部分居民基础负荷。
6. 明星选手公开质疑俱乐部将妖怪伤病包装成“拼搏精神”。

### 数据边界

- `SubRegionSO` 保存正式 ID、显示名称、图标、地图资源和运行时引用。
- 长篇社会、生态和剧情说明继续保留在 Markdown。
- 卡牌只引用 `WorldRegionSO`、`SubRegionSO` 与必要的 `LocalAreaSO`，不要复制地区长文本。
- 具体竞技场、建筑和场景可以使用 `LOC_` 标识，但不构成第四级地理层级。
- ID 一旦进入存档、网络协议或正式资源，不应随意修改。
