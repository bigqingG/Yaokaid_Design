# 九川地区·澄曜区设定档案

> 文档版本：1.6  
> 正史等级：C2 制作中设定  
> 子地区 ID：`REG_CHENGYAO`  
> 所属世界级地区：九川地区（`WR_JIUCHUAN`）  
> 子地区类型：现代新能源都市区  

> 地理层级说明：澄曜区是九川地区下的第二层子地区，不等同于现实城市中的普通市辖区。区内的核心城区、县域、镇村、产业带、生态区和大型基础设施统一属于第三层地方单元。

> 区域完整性说明：澄曜区拥有独立的食品与能源供应、交通物流、制造商业、教育医疗、媒体文化、公共服务、妖怪管理和竞技体系。新能源、职业竞技与商业媒体是比较优势，不是由澄曜垄断的九川级职能。

## 1. 一句话印象

> 以新能源产业、职业竞技与商业媒体闻名的现代都市区。西侧与西北、西南分布着静湖镇、雾湖镇和由燃栖城管辖的大片红沙红岩城郊地带，东侧是高度城市化的澄曜主市区，南侧临海。玩家从西南的雾湖镇出发，在各镇的挑战俱乐部与保护区中，从协行者一步步成长为御灵师。

## 3. 地理结构与地方单元

澄曜区不是单一城市。东侧为高度城市化的**澄曜主市区**（地图右侧），由曜心城区、赤轨新城、曜南竞技公园等组成；主市区西侧相邻的是由独立城市**燃栖城**管辖的**燃栖城郊带**——大片红沙红岩的生态—半荒漠地带；西北为**静湖镇**，西南为**雾湖镇**，东北为**澄湖镇**。南侧临海，海岸线内凹处为澄曜港口。澄青河从静湖镇与雾湖镇之间穿过，在城郊带形成大量支流，最终流向主市区南侧，从港口入海。

### 3.1 曜心城区（含镜幕商环）

澄曜主市区的核心，也是全区行政、商业与文化主体城区。高层建筑与中层街区混合分布，沿街设置骑楼式遮阴空间、林荫步道和小型公共广场。建筑光伏主要安装在屋顶、站棚、遮阳构件和不透明外墙板上，用于就地发电；临街立面以低反射材料为主。

**镜幕商环**是曜心城区**内部的一部分**，不是与曜心城区平级、独立占地的地区。“镜幕”是早期影院和赛事转播业留下的历史地名，并不表示建筑普遍采用镜面外墙；今天的商环由商业综合体、媒体中心、剧场、步行街和公共广场组成，大型显示设施集中在场馆与获批商业节点，并受亮度、时段和朝向限制。地图 UI 上镜幕商环可作为独立可选区域，但世界观空间层级归属曜心城区。

**主要功能：** 职业联赛主会场、卡牌交易中心、联盟办事处、明星选手与赛事媒体聚集地；镜幕商环承担赞助活动、卡牌新品发布、城市挑战赛、表演赛和选手商业代言。

### 3.2 赤轨新城

位于澄曜主市区北侧外缘，与中心城区相连，是主市区组成部分之一。城区围绕新型轨道交通、储能设施和企业总部建设，车站、住宅、学校、社区服务和就业中心混合布局，部分高架区段下方被改造成球场、雨棚市集和连续绿道。

**主要功能：** 赤轨俱乐部总部、扬子江光学电力研发中心、企业训练营和青年技术人员社区。

### 3.3 曜南竞技公园

位于澄曜主市区南侧，南邻海岸、东近港口，与曜心城区相邻。园区综合训练、青少年赛事、公开挑战和市民休闲于一体，大型场馆之间保留成片树荫、雨水花园、公共球场和日常开放的慢行环线，非赛期仍是普通市民使用的城市公园。地图上保持其作为单独地区的 UI 辨识度。御灵师资格试炼（御灵大考）的区级考场设于此。

**主要功能：** 新手教学赛、学院联赛、俱乐部试训、赞助商测试卡、节庆活动与御灵大考。

### 3.4 澄曜港口

澄曜区南侧海岸向陆地凹入的港湾，位于曜南竞技公园东侧、曜心城区南侧，是澄青河的入海口。港区承担沿海客运、货运与渔业码头职能，也是主市区与海岸联系的枢纽。

**主要功能：** 客货海运、渔业码头、河海转运、滨海城市界面；港口正式名称待确认，暂称“澄曜港口/主港区”。

### 3.5 燃栖城郊带

位于澄曜主市区西侧并与之相邻，但**不属于主市区**；它是独立城市燃栖城的主要管辖范围，应理解为由燃栖城管辖的大型外围地区，而非普通意义上的“主城区绿色郊区”。

地带以大面积**红沙、红色岩石、红色裸岩与局部巨大岩体**为主体地貌，地表偏干燥、沙化明显；它不是传统沙漠——澄青河的多条支流穿行其间，支流附近形成局部绿色生态走廊，分布植被、湿地与草地。正确关系是：**红沙红岩是大面积主体，河流与支流周边是条带状绿洲**。城郊带中很大一部分属于红谷生态区，燃栖城南方还有具体地貌“红谷”。

**主要功能：** 红谷生态区生态承载、支流绿廊农业与栖息、城郊聚落、能源与交通走廊、沙化治理与生态保护剧情。

### 3.6 燃栖城

澄曜区内的一座**独立城市聚落**，位于燃栖城郊带内部，不属于东侧的澄曜主市区；与主市区距离较近，两者主要通过动车连接。燃栖城实际建成区面积小于其行政/管辖范围——它管辖整个燃栖城郊带，城周围是大片红沙红岩生态、河流支流与少量聚落。燃栖俱乐部延续城郊地带硬朗的地方传统，并与赤轨俱乐部保持官方青训合作。

**主要功能：** 城郊带行政与公共服务中心、燃栖俱乐部所在地、赤轨青训选拔、动车进入主市区的枢纽节点。燃栖城人口、具体产业与详细历史待确认，本档案不写死。

### 3.7 红谷生态区

燃栖城郊带中的大型生态区域，占城郊带很大一部分，**不等同于单一峡谷**。区内大面积红沙与红岩地貌交错，澄青河支流穿行，局部水源地附近生态更丰富，生活着大量妖怪，是澄曜区重要的妖怪生态区域。区内可同时存在红沙荒地、红色岩柱、红岩丘陵、河道支流、河岸绿带、妖怪活动区以及少量人类道路与设施。协行者保护区玩法中的红谷片区即位于本生态区内。

**主要功能：** 妖怪栖息与迁徙、保护区巡护实战、支流生态、生态旅游与偷猎/非法克隆风险剧情。生态区成立年份、保护机构名称与具体种群清单待确认。

### 3.8 红谷与红谷历史道路

“红谷”与红谷生态区不是同一概念：红谷是**燃栖城南方的一处具体大型地貌**——两侧为巨大的红色岩壁，中间形成一条明显的谷地通道，谷底有一条道路，可理解为被巨大红色岩体夹住的天然交通走廊。

历史上很长一段时间里，红谷道路是**青棠区（位于澄曜区西侧）前往澄曜城区的主要甚至唯一通道**，因此红谷不仅是自然地貌，也是历史交通节点。现代动车与其他交通体系建立后，不再只有红谷道路可通行；红谷道路现代是否仍承担公路主干道功能待确认，不写死。

**主要功能：** 历史交通遗迹、峡谷场景、青棠—澄曜关系叙事、遗迹保护与道路定位争议剧情。

### 3.9 静湖镇

位于澄曜区**西北方向**，三镇中最靠近区西侧，有动车线路经过（线路经燃栖城方向接入主市区）。澄青河主河道从静湖镇与雾湖镇之间通过。镇旁湖面常年平静，镇上多静修馆、旧书铺与观水台；明镜俱乐部以慢速控制、冥想对局和法术基础教学闻名。

**主要功能：** 控制与防守教学、法术卡入门、协行者二阶考核、湖心静修支线、动车站点。

### 3.10 雾湖镇（玩家初始地）

位于澄曜区**西南方向**，有独立方向的动车线路通往澄曜主市区；与静湖镇之间是澄青河主河道通过的重要区域。镇旁湖面清晨与黄昏常起大雾，镇中多木屋、栈桥与晨市，生活节奏缓慢。镇上设有妖怪登记点、卡牌发放窗口与晓雾俱乐部，是玩家完成安全考核、领取初始卡牌、收服第一只妖怪的新手村。

**主要功能：** 玩家出生与存档点、新手教学、妖怪登记、协行者一阶考核、动车站点与公路起点。

### 3.11 澄湖镇

位于澄曜区**东北方向**，有动车线路直接连接澄曜主市区，线路最终接入主市区的市区中心站。镇旁湖面开阔清透，镇内设湖产市集、中型会馆与巡回赛会场，澄光俱乐部是湖盆方向巡回挑战赛的总决赛举办地。

**主要功能：** 巡回赛总决赛、法术进修、协行者高阶考核、动车直达主市区、进入职业都市前的最后一站。

## 4. 环境、气候与建成空间

### 4.1 区位与气候

- 澄曜位于九川南部，也是该国靠近世界赤道一侧的低纬城市带之一。
- 全年日照资源充足，高温季节较长，空气湿度偏高，常见短时强降雨和季风天气。
- 澄青河从静湖镇与雾湖镇之间穿过，向澄曜区内部延伸，沿途形成大量支流，部分支流进入燃栖城郊带；支流附近是城郊带少数明显湿润、适宜植被生长的地区。
- 燃栖城郊带整体偏干，红沙红岩广布，风沙天气多于主市区；湿润范围仅沿支流呈条带状分布。
- 主市区南侧临海，受海洋与河口水网调节；中心城区存在热岛效应，但其严重程度受街区密度、树冠覆盖、通风廊道和地表材料共同影响，不将“灼热难居”视为城市常态。

### 4.2 气候适应

- 街道普遍采用行道树、深檐、连廊、可开启遮阳板和透水铺装，为步行与骑行提供连续遮阴。
- 轨道站、学校、医院、体育公园和社区中心设有饮水、避雨与高温时段开放的公共纳凉空间。
- 雨水花园、下沉绿地和调蓄池用于应对短时强降雨，同时构成普通城市妖怪的栖息点。
- 建筑群通过退台、架空层和通风廊道组织盛行风，减少对机械制冷的单一依赖。
- 城郊带村镇与巡护点依托支流绿廊布置水源与绿地，红沙路段设防沙植被带、导视与避风沙掩体。

### 4.3 建筑光伏与玻璃幕墙规则

- 澄曜所谓“太阳能幕墙”是建筑光伏一体化立面：光伏组件同时承担发电与部分围护、遮阳功能。它不具备、也不允许具备将阳光定向反射至街道的用途。
- 光伏立面优先布置在屋顶、站棚、遮阳板和不透明外墙面；需要采光的部位可使用半透明组件，但必须满足室内采光、隔热、防火、检修和鸟类友好要求。
- 玻璃与光伏工程在审批前必须完成全年反射眩光模拟。面向道路、住宅、学校、医院和公共活动场地的立面采用低反射材料，不得形成持续眩光、聚光热斑或影响交通视线。
- 可转向反射构件仅能用于封闭式能源试验场，并设置失效归零和人工切断机制。把反射光束导向地面、人群或相邻建筑属于明确违法行为。
- 建设、环境与交通管理部门分别负责方案审批、光环境复核和道路安全评估。违规设施可被责令立即停用、限期整改并追究损害责任；赛事项目还会受到场馆许可和联盟资格处罚。

### 4.4 户外显示与高架交通规则

- 户外显示设施集中在竞技场、交通枢纽和少数商业节点，必须自动适应环境亮度；住宅界面、生态廊道和夜间道路禁止使用持续高亮、快速闪烁的内容。
- 大型赛事结束后，外屏按规定时段关闭或转入低亮静态公共信息模式。临时活动若需延长点亮时间，必须单独报批并承担妖怪生态监测。
- 高架轨道只在客流与地形确有需要的区段使用，并受噪声、振动、遮阴和街区连通性评估约束；学校、医院和密集住宅附近优先采用地下、地面或全封闭低噪方案。
- 高架下空间不得成为连续灰色隔离带，应安排照明、排水、绿化、慢行通道或社区设施，并保留足够的横向步行联系。

## 5. 产业与居民生活

### 5.1 核心产业

- 新能源研发、设备制造与并网服务
- 建筑光伏、储能与城市能源管理
- 轨道交通、港口航运与城市维护
- 职业竞技与俱乐部经济
- 赛事媒体、广告和卡牌发行
- 消防、安保与巡检妖怪服务
- 城郊带支流绿廊农业、红谷生态管护与相关旅游

### 5.2 居民生活

居民重视效率、专业能力和公共信誉。年轻人普遍熟悉职业联赛、俱乐部排名和赞助活动，但日常生活同样由通勤、学校、社区商业、公园活动和家庭关系构成。主市区公共服务密集，西北、西南、东北三镇保留湖滨小镇的商业与生活节奏，燃栖城作为独立城市服务于整个城郊带。城郊与主市区之间存在资源分配与沙化治理争议，但不被描写成被城市抛弃的牺牲区。燃栖城的人口、产业结构与历史尚未确认，不在此写死。

## 6. 妖怪生态

### 6.1 常见生态类型

- 吸收热量或光能的城市妖怪
- 栖息在轨道、金属设施、能源站与港口设施附近的妖怪
- 适应建筑遮阴、树冠和夜间常规照明的城市夜行种群
- 用于消防、巡检和安保的工作妖怪
- 栖息于静湖、雾湖、澄湖湖滨及澄青河水岸的水、木系种群
- 栖息于红沙红岩地貌、适应干热与风沙的火、金系种群
- 依赖支流绿廊与水源地、在红谷生态区集中活动的种群
- 河口、港湾与滨海种群

### 6.2 生态与社会议题

- 个别违规赛事照明或临时活动扰乱夜行种群
- 能源、交通与港口扩建可能切断旧有栖息廊道
- 企业驯养种群与野生种群差异扩大
- 竞技训练过度消耗妖怪
- 火元素浓度与人工天气叠加造成城市热风险
- 燃栖城郊带沙化压缩妖怪栖息地，支流断流直接威胁绿廊种群
- 红谷生态区外围的偷猎、非法克隆与未登记收服问题
- 河口港区开发与滨海妖怪栖息的冲突

### 6.3 设计底线

- 妖怪外形必须先满足生物轮廓与生态逻辑，再叠加元素表现。
- 元素不应被简化成固定颜色、发光或机械装饰。
- 本区代表妖怪不应全部围绕职业竞技；必须保留工作、野生、家庭和地方生态种群。
- 卡牌效果应尽量从行为、产业用途、天气关系或社会处境中产生。
- 红沙红岩地貌中的妖怪应体现干热适应性，不照搬荒漠题材；红谷生态区具体种群清单在确认前列为待确认，不擅自补完。

### 6.4 妖怪档案入口

澄曜区第一批妖怪物种档案见[澄曜区妖怪设定索引](../02-妖怪设定/_妖怪设定索引.md#2-澄曜区妖怪)。当前均为 C3 候选设定，卡牌战斗数值仍以卡牌设计文档为准。

## 7. 社会文化

- 本区社会气质以“明亮、快节奏、商业化、竞争激烈”为主，但内部必须保留主城、独立城市、湖滨镇与城郊地带的阶层、城乡和代际差异。
- 本区竞技传统应与产业和居民生活有关，不能只靠俱乐部口号区分。
- 赞助商、俱乐部、公共机构、居民组织与妖怪保护方应拥有不同利益。
- 西行一带有“过镇留印”的说法：协行者在晓雾社取雾湖印，在明镜社取静湖印，在燃栖的红谷生态区取火印，再到澄光社取澄湖印，四印齐备方有资格报考御灵师。
- 红谷道路是西行商路记忆的象征，老一代常以“走过红谷”形容真正见过世面。
- 地方文化应通过节庆、语言习惯、工作流程、建筑和日常关系体现，而不是依赖长篇说明。

## 8. 视觉语言

### 8.1 核心视觉关键词

- 南方强日照下的浅色墙面、暖色遮阳构件与清晰天际线
- 车站光伏顶棚、建筑外遮阳和可见的能源维护结构
- 林荫主路、骑楼式步行空间、雨水花园与普通社区公园
- 动车线路、地面公交和慢行网络共同构成的立体交通
- 赛事期间出现的旗帜、导视和受控场馆屏幕
- 燃栖城郊带大面积红沙、红岩、岩柱与巨大岩体，支流沿岸条带状绿洲
- 红谷两侧高耸红色岩壁与谷底古道
- 南侧内凹港湾、港口码头、河口滩涂与滨海城市界面
- 西北静湖的镜面水面、西南雾湖的晨雾栈桥、东北澄湖的开阔晴光
- 镇口挑战俱乐部的木牌、印记榜文与保护区入口的警示木栅

### 8.2 地图美术与 UI 要求

- 澄曜区地图采用**二次元、卡通、动漫游戏地图**风格：非写实、非照片感、非卫星图，不过度锐利，不做复杂 3D 写实城市；保持柔和轮廓、简化建筑、卡通化地貌、明确色块与清爽的高可读性，可使用轻微 3/4 俯视游戏地图视角。
- 城镇与城区在地图上表现为**轻微悬浮于地形之上的可交互地图节点**：有独立边缘、轻微高度差、柔和投影和局部底座，明显可点击；不得把城镇直接画死在底图里。
- 悬浮节点不使用厚重科幻 HUD、不过度发光、不走赛博朋克风。
- 各城镇、城区、铁路、地名与关键地标必须能从底图中独立拆分为 Sprite/UI，支持悬浮高亮、选中、放大、发光、位移、边框变化与点击进入。
- 地图支持黑幕逐步解锁，单独显隐：雾湖镇 → 静湖镇及周边 → 燃栖城及燃栖城郊带 → 市区中心站与澄湖镇 → 完整澄曜区；不得把全部内容烘焙进一张不可拆分的大底图。

### 8.3 禁止倾向

- 全区赛博朋克化
- 所有金元素妖怪机甲化
- 只使用霓虹夜景
- 忽视学校、住宅和基层工作场景
- 把火元素等同于全身燃烧
- 用连续反光玻璃、刺眼光束或全天候巨屏表现“新能源”
- 把高温和商业化写成居民长期忍受污染的城市常态
- 把燃栖城郊带整体画成绿色平原；红沙红岩必须是主体，绿洲只沿支流分布
- 把红谷生态区画成纯荒漠或纯荒原；其中应有支流、绿带、巡护设施与妖怪活动痕迹
- 把三座湖镇画成毫无差异的同一片水景；必须分别体现西北静、西南雾、东北澄开的气质
- 把市区中心站拆成多个互相独立的“中心站”

### 8.4 卡图构图要求

- 妖怪是画面主体，但背景必须能识别所属区和具体地方。
- 同一区不能让所有卡图使用同一种天气、时间或地标。
- 背景应体现工作、生活、生态或剧情，而不是纯装饰。
- 避免直接生成卡框、文字、数值、Logo 和 UI 元素。

## 9. 代表组织

### 9.1 赤轨俱乐部

商业影响力极强，强调主动进攻、镜头表现和数据化训练。内部存在“竞技成绩优先”与“选手品牌优先”的路线争议。赤轨在燃栖城设有官方合作青训点，每年从燃栖俱乐部的毕业协行者中选拔试训学员。

### 9.2 扬子江光学电力公司

**业务与卡池术语方向：**

- 峰值功率
- 过载
- 并网
- 储能
- 负荷调度
- 热管理
- 光伏阵列
- 建筑光伏一体化
- 低反射封装
- 遮阳调度
- 紧急供电
- 光学巡检
- 削峰填谷

**适合的赞助卡机制：**

- 短期获得高额资源或伤害，之后承担代价

## 10. 城镇交通体系

各镇、独立城市与主市区之间通过公路、大巴与动车连通。交通既是叙事场景，也是玩法上的移动与门槛系统。

### 10.1 公路与大巴

- **城际/城乡大巴**票价低廉、沿线停靠，开局即可乘坐，连通雾湖镇、静湖镇、澄湖镇、燃栖城与澄曜主市区，是协行者早期最主要的移动方式。
- 公路在城郊带沿红沙岩体与支流绿廊穿行；燃栖城南方的红谷谷底道路是历史上青棠入澄曜的古道，现代道路定位待确认。
- 大巴接受妖怪携行：已登记的小体型妖怪可随客乘车，大体型妖怪须收入携行卡或乘坐带货运厢的专门班次；未登记妖怪禁止上车。
- 西南雾季、城郊风沙与暴雨天气下公路可能减速或临时停运，候车点常因此成为支线事件发生地。

### 10.2 动车系统

- 澄曜主市区与各镇之间开行动车组（粗黑线为线路、黑点为车站；草图中线路断开仅为避让文字，不代表中断）。
- 三个方向的线路为：静湖镇方向（经燃栖城）、雾湖镇方向、澄湖镇方向；**三个方向的线路最终汇集到主市区同一个「市区中心站」**，不得拆成多个中心站。
- 静湖镇、雾湖镇、澄湖镇与燃栖城均设动车站，主市区中心站为总枢纽。
- 购票与乘车实行实名管理，须出示卡牌携行执照；部分车次对协行者阶位和妖怪登记状态有要求，无证或未登记者无法通过检票。
- 动车线路与车站的正式名称、各站间距待确认，暂以方向称呼。

### 10.3 交通玩法规则

- 移动消耗车票（游戏货币）与时间：大巴最便宜，动车最快但票价与门槛更高。
- 极端天气（雾、风沙、暴雨）会延误、改线或封线，玩家可选择等待、改乘交通工具或沿栈道步行探索。
- 交通节点设置商店、公告板、任务榜和存档点；城镇之间以车次时刻表作为场景切换，不做连续开放公路。

## 11. 称号与晋级体系

### 11.1 两个基本称谓

- **协行者**：通过基础安全考核、完成妖怪与卡牌登记，以“与妖怪结伴同行”方式修行的新手和地方选手的统称。协行者既驯服妖怪进行对战，也修习法术、以法术卡介入战斗，但尚不能独立承担公共安全与教学职责。
- **御灵师**：通过区级御灵师资格试炼（俗称“御灵大考”）的资深者称号。御灵师能独立统御妖怪、施术作战，并对妖怪福利、对战安全与公共秩序负责，可担任俱乐部教练、保护区巡查、会馆馆主或接受职业联盟注册。

### 11.2 晋级阶梯

| 序 | 称号 | 取得条件 | 解锁内容 |
| --- | --- | --- | --- |
| 1 | 见习协行者 | 在西南雾湖镇出生登记，完成新手安全教学，领取初始卡牌 | 晓雾俱乐部教学赛、雾湖湿地保护区、大巴乘车 |
| 2 | 协行者（正式） | 通过晓雾俱乐部一阶挑战：收服 1 只妖怪、取得 1 场正式对战胜利、掌握 1 张基础法术卡，取得雾湖印 | 西北静湖镇、静湖保护区、明镜俱乐部考核 |
| 3 | 红谷协行者（资深） | 取得静湖印，在燃栖俱乐部通过考核并在红谷生态区完成实战巡护，取得红谷火印 | 燃栖城、燃栖城郊带、红谷片区、赤轨青训试训报名 |
| 4 | 巡曜协行者（准御灵） | 取得澄湖镇澄光俱乐部考核澄湖印，乘动车经市区中心站进入主市区 | 澄湖镇、市区中心站、曜心城区与主市区全部内容 |
| 5 | 御灵师 | 在曜南竞技公园通过御灵大考：多回合对战、法术实操、保护区实战与规则笔试合格 | 职业联盟注册、俱乐部签约、跨区旅行证、开设会馆/收徒资格 |

### 11.3 与地图解锁与既有竞技体系的关系

- 称号进度与地图黑幕解锁顺序一致：雾湖镇 → 静湖镇及周边 → 燃栖城及城郊带 → 市区中心站与澄湖镇 → 完整澄曜区。
- 协行者对应既有赛事层级中的“地方单元阶段”（地方积分赛、俱乐部资格赛）；御灵师对应“区级阶段”以上，区级大师赛优胜者民间称“小王”。
- 御灵师之上的高级御灵师（对应区级大师、九川大师“大王”）阶位设计为 C3 远期内容，不在首发版本展开。
- 该称号与考核体系当前为澄曜区地方制度；是否为九川统一认证、其他五区是否互认，列入待确认事项，确认前不写成九川通则。
- 晋级只认对战与试炼成绩及妖怪福利考核，不允许以赞助费、代言合同替代考核，这是御灵大考规则的底线，也是剧情冲突点之一。

## 12. 核心矛盾

### 12.1 表层问题

职业赛事高速扩张，俱乐部、企业与媒体不断提高比赛规模和商业曝光；越来越多协行者把“尽快成为御灵师、签下职业合同”视为唯一目标，西行的红沙地带也承受着开发与沙化压力。

### 12.2 深层原因

- 赛事商业价值开始压过竞技与妖怪福利
- 企业掌握训练资源、克隆设备和曝光渠道
- 燃栖城管辖的城郊带承担沙化、开发与生态保护的多重成本
- 年轻选手把签约视为唯一上升通道
- 基层挑战俱乐部经费与认证权受制于职业联盟和赞助商
- 历史通道（红谷道路）在现代交通体系中的定位悬而未决

### 12.3 主线命题

> 当竞技成为一座城市最重要的商品，选手与妖怪还能否决定自己以何种方式被看见？古道与绿洲所见证的修行，又是否注定要被标价？

### 12.4 冲突设计要求

- 不将企业统一写成纯粹反派。
- 不让公共机构只承担说明规则的功能。
- 冲突必须涉及真实利益分配与持续后果。
- 结局应改变人物关系、区级制度、产业安排或妖怪生态中的至少一项。

## 13. 游戏玩法映射

| 世界观内容 | 玩法表达              |
| ----- | ----------------- |
| 能源峰值  | 本回合爆发，之后承担资源或生命代价 |
| 城市快节奏 | 低费连打与连击           |
| 职业曝光  | 打出多张牌后追加收益        |
| 过载设施  | 消耗生命、耐久或下回合资源     |
| 轨道调度  | 快速移动或换位           |
| 城郊维护  | 低费单位离场后提供修复与资源    |
| 红沙城郊带 | 干热主题区域：风沙天气、沙化治理与支流绿洲点位 |
| 大巴    | 低成本移动，附带随机遭遇与天气延误 |
| 动车汇聚  | 高成本快速移动，三方向线路汇聚中心站，需执照与阶位解锁 |
| 过镇留印  | 俱乐部挑战与保护区考核收集印记，按地图顺序解锁新区域 |
| 御灵大考  | 毕业型综合关卡：对战 + 法术 + 实战 + 规则 |
| 保护区收服 | 2D 探索中遭遇、捕捉妖怪与拾取法术回路 |
| 港口入海  | 河口与海运场景，远期通向其他沿海地区 |

该区的卡组不能只有单一套路，至少应设计：一个主流构筑、一个偏控制或资源的替代构筑，以及一个由玩家探索出的跨区混合方向。

## 14. 剧情钩子

1. 赤轨俱乐部准备签下一名未成年选手，但合同包含其妖怪的长期商业使用权。

### 数据边界

- `SubRegionSO` 保存正式 ID、显示名称、图标、地图资源和运行时引用。
- 长篇社会、生态和剧情说明继续保留在 Markdown。
- 卡牌只引用 `WorldRegionSO`、`SubRegionSO` 与必要的 `LocalAreaSO`，不要复制地区长文本。
- 镜幕商环在空间层级上归属曜心城区，其 `LocalAreaSO` 仅服务于 UI 独立选取与任务定位，不表示二者平级。
- 称号与阶位建议由独立的 `TitleSO`/晋级配置表维护，本档案只提供名称、顺序与取得条件。
- 交通线路、车次时刻、票价与地图黑幕解锁顺序建议由配置表维护，节点引用对应 `LocalAreaSO`。
- 具体竞技场、建筑和场景可以使用 `LOC_` 标识，但不构成第四级地理层级。
- ID 一旦进入存档、网络协议或正式资源，不应随意修改。
