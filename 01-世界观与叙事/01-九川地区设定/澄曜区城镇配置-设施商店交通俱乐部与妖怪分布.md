## 0. 这份文档解决什么

《澄曜区.md》已经确定了**有哪些地方单元、四家挑战俱乐部、四处保护区和三方向动车线**，但没有规定玩家进入每个城镇后具体能用到哪些设施、几家商店、在哪里上下车、在哪里对战、在哪里遇到哪些妖怪。本文把这些内容落成一份可直接转 Unity 配置（`RegionConfig` / `ReserveConfig` / `FacilitySO` / `EncounterConfig`）的城镇内容表。

**三条总原则：**

1. **只配置、不新造地理层级。** 所有设施都是地方单元（`AREA_`）之下的具体场景（`LOC_`），不产生第四级地区；镜幕商环仍归属曜心城区，仅 UI 独立。
2. **设施密度跟随成长线。** 雾湖镇小而全（教学需要），越靠近主市区商业与竞技设施越密集；红谷生态区与燃栖城郊带是野外，不按城镇配商店。
3. **妖怪分布只写有依据的。** 已建档妖怪以《妖怪设定索引》的“常见地方单元”为准；补充卡池 CYS_023–042 为**候选分布建议**；世界观承诺但尚无物种的生态位标为**空缺**，只给生态位描述，不擅自命名、不定为正史。

## 1. 怎么做：配置方法

### 1.1 六类设施模型

每个地方单元按同一套类型清点，六区通用，便于后续其他区复用：

| 类型   | 代码    | 包含                                                               | 玩法职能             |
| ---- | ----- | ---------------------------------------------------------------- | ---------------- |
| 公共服务 | `PUB` | 妖怪登记点、卡牌发放窗口、联盟办事处、公告板/任务榜、妖怪医疗与福利站                              | 登记、考核报名、规则与任务、恢复 |
| 竞技设施 | `FAC` | 挑战俱乐部会馆、职业俱乐部、竞技场/赛场、试训与练习场                                      | 教学对局、晋阶考核、赛事、试训  |
| 商店   | `SHP` | 见 1.2 五种店型                                                       | 购买、出售、整备补给       |
| 交通节点 | `TRF` | 动车站 `RAIL`、长途汽车站 `BUS`、码头 `PIER`、市内接驳点 `SHUTTLE`、公路候车点 `BUSSTOP` | 区域移动与门槛          |
| 整备点  | `RST` | 客栈/营地/招待所（存档点）                                                   | 存档、休息、恢复、整备      |
| 生态设施 | `ECS` | 保护区入口营地、巡护站、观察站、补给箱、调查点                                          | 保护区探索循环          |

### 1.2 五种店型与分级

| 店型       | 代码   | 主营                  | 典型库存方向                   |
| -------- | ---- | ------------------- | ------------------------ |
| 卡牌店      | `S1` | 单卡、卡包、牌组耗材、卡牌保管     | 基础单卡 → 进阶单卡/交易/拍卖        |
| 道具耗材店    | `S2` | 收服耗材、携行卡、药品、冒险与巡护装备 | 封印耗材、恢复药、天气/防沙装备         |
| 市集杂货     | `S3` | 食材、素材、地方特产、礼物       | 料理素材、妖怪亲合礼物、 crafting 素材 |
| 赞助/设备服务点 | `S4` | 赞助商服务卡、设备牌、企业合作     | 仅城市节点；受阶位与剧情解锁           |
| 特色专营店    | `S5` | 法术回路、旧书、静修、锻造维护等    | 按城镇主题差异化，不做成同质店          |

商店分三级，决定库存深度（具体库存单独立表，本文只定店数与等级）：

- **T1 基础级**：新手村与小镇，教学耗材、低阶商品；
- **T2 标准级**：澄湖镇、燃栖城，进阶卡与法术、巡护装备，首次出现受限的 S4；
- **T3 齐全级**：主市区，全品类、交易与拍卖、赞助旗舰服务。

> 妖怪登记点与卡牌发放窗口是**公共服务**（免费、教学），不计入商店；卡牌店是**商业**售卖，二者不能合并计数。

### 1.3 数量配置与成长阶梯对齐

| 成长阶段（称号） | 可进入区域 | 设施配置逻辑 |
| --- | --- | --- |
| 见习协行者 | 雾湖镇、雾湖湿地保护区、大巴 | 小而全：登记/发牌/教学/基础商店/存档齐备，但只有 1 家俱乐部、1 处低危保护区 |
| 协行者（正式） | 静湖镇、静湖保护区 | 增加法术特色店、夜行与控制教学 |
| 红谷协行者 | 燃栖城、燃栖城郊带、红谷片区、赤轨青训报名 | 独立城市配套，首次出现巡护装备店与受限 S4 |
| 巡曜协行者 | 澄湖镇、市区中心站、主市区全部内容 | 进阶卡牌、法术进修、决赛会场、动车直达 |
| 御灵师（大考后） | 曜南竞技公园考场、曜心城区职业体系、跨区 | 职业联盟注册、交易中心、赞助旗舰、跨区码头 |

### 1.4 ID 规范

- 设施：`LOC_<地方单元缩写>_<类型>_<序号或功能>`，如 `LOC_WUHU_SHOP_S2_01`、`LOC_RANQI_RANGER_HQ`。
- 地方单元缩写：`WUHU`（雾湖镇）、`JINGHU`（静湖镇）、`CHENGHU`（澄湖镇）、`RANQI`（燃栖城）、`OUTSKIRTS`（燃栖城郊带）、`HONGGU`（红谷生态区）、`CORE`（曜心城区）、`RING`（镜幕商环）、`REDRAIL`（赤轨新城）、`YAONAN`（曜南竞技公园）、`HARBOR`（澄曜港口）。
- 已在《澄曜区.md》中出现的 `LOC_`（五座动车站、四所俱乐部会馆、红谷古道）保持不变，本文沿用。
- 本文新增 ID 在进入存档/网络协议前允许调整。

### 1.5 计数口径（避免后续对不上账）

- **俱乐部**只计两类：挑战俱乐部（基层会馆）与职业俱乐部总部；青训点、公共赛场、试训场、表演场**不计入**俱乐部数。
- **保护区**按协行者可进入的玩法保护区计；红谷片区在“燃栖城”行计 1 处（它坐落在红谷生态区内、由燃栖城管辖），红谷生态区行注明同一处，不重复计。
- **动车站**以《澄曜区.md》第 10.2 节为准，共 5 座；赤轨新城、曜南、镜幕、港口不设城际动车站。
- **长途汽车站**分两级：`BUS` 客运枢纽（始发/终到，计入定额，全区 5 座，对应主档大巴连通的五个方向节点）与配客站/沿线候车点（`BUSSTOP`，含港城汽车站这类码头接驳站，不计入定额，按需布设）。
- 镜幕商环的商店数在表内单列（UI 独立选取），按行政空间统计时并入曜心城区。
