# 核心玩法概述
妖怪牌是倾向于CCG类型的卡牌游戏
## 游戏主循环
获取卡牌 → 构筑卡组 → 进行对战 → 获得奖励 → 获取新卡牌

## 对战循环
回合开始 → 法力恢复+抽牌 → 行动（部署单位、使用法术、操作单位）→ 攻击 → 回合结束 → 敌方回合
## 预期对战时长
预期对战时长在5-10分钟
## 回合阶段 
具体参考 #标准回合流程设计 

| 阶段       | 内容                    |
| -------- | --------------------- |
| 1. 回合开始  | 触发回合开始效果、天气 Tick      |
| 2. 资源获取  | 正常增加1点法力槽（增长上限12），法力补满，抽1张牌 |
| 3. 出牌/行动 | 消耗法力部署单位、施放法术         |
| 4. 攻击    | 单位攻击                  |
| 5. 回合结束  | 触发回合结束效果，天气倒计时        |
| 6. 敌方回合  | 重复以上流程                |



## 胜负条件
将对方玩家生命值降至 0 即获胜。

## 卡组构筑
游戏要求并鼓励玩家自行进行卡组的设计构筑，目前计划是采用   ==主地区+副地区==
的方式，让玩家选择对应地区的妖怪进行卡组构筑。

## 关于赞助商
玩家在选择主副地区时，需要选择该主地区对应的赞助商，不同地区具有不同赞助商，其目的是为了丰富对战内容，拓展乐趣。不同的赞助商具有不同的牌库，当玩家在游戏中触发了”打造一张赞助牌“效果，将能够在其所选赞助商牌库中Discover一张牌（三选一：抽三张牌选一张加入手牌中）。针对卡组特点灵活选择赞助商将会是制胜关键。

## 关于法力
初始法力值和法力槽数均为0。每个我方回合开始时，正常增加1点法力槽（增长最高到12），然后将当前法力补满。效果“额外获得1点法力槽”只增加最大法力，不补充当前法力：1/3变为1/4，下回合正常增槽并补满后为5/5。效果额外获得的槽数可突破12；超过12时正常增长不再增加槽数，也不减少现有槽数。具体文案遵循《卡牌文本规范》。

## 核心策略维度
1. **法力管理**：何时铺场、何时留费反制
2. **位置策略**：2×5 棋盘前后排布局
3. **元素克制**：五行相克影响战斗结果
4. **天气博弈**：利用天气增强己方元素、削弱对方
