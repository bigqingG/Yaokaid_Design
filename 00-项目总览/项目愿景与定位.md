# 妖斗牌 — 项目愿景与定位

## 一句话描述
妖斗牌是一款以东方妖灵世界观为背景的回合制卡牌对战游戏，玩家在五行元素与天气变化的策略维度下构筑卡组、指挥妖灵作战。

## 项目演进
| 阶段   | 代号         | 题材     | 状态                 |
| ---- | ---------- | ------ | ------------------ |
| 原型验证 | 第三战线 / 异兽牌 | 军事卡牌   | ✅ 已完成核心框架验证、向妖怪牌过渡 |
| 商业版  | 妖怪牌        | 东方妖灵卡牌 | 🔧 开发中             |

### 原型→商业版关键转变
- **世界观**：军事阵营（不列颠尼亚/中州/弗朗西/沃斯托克）→ 妖灵/仙门/人间三大阵营
- **卡牌类型**：Hero/Support/Apostle/Spell/Hex → 英雄/支援/使徒/法术/咒术
- **资源系统**：经济点+科技点 → 统一法力值（Mana）
- **元素系统**：无 → 五行元素（木/火/土/金/水）+ 元素反应
- **天气系统**：无 → 动态天气影响元素反应概率
- **战场**：先锋/支援双区 → 2×5 棋盘（前排/后排）
- **技术栈**：Mirror 网络预留 → Nakama 服务端

## 目标用户
- 核心受众：喜欢卡牌策略 + 东方奇幻题材的玩家
- 年龄层：16–35 岁
- 平台：移动端优先（iOS/Android），PC 兼容

## 竞品参考
- 炉石传说（卡牌对战基础体验）
- 漫威 Snap（快节奏 + 位置策略）
- 阴阳师：百闻牌（东方题材卡牌）
- Kards：军事卡牌游戏

## 核心差异化
1. **五行元素反应**：攻击和法术携带元素属性，产生克制/增强反应
2. **动态天气**：天气影响元素反应概率
3. **2×5 棋盘**：前后排保护机制，位置决定战术

## 当前定位
以单机对战 AI 为主的完整对局体验，网络对战作为后续扩展方向。
