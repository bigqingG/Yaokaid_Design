# 卡牌演出编排

## 统一表现框架
EffectPresentationService 管理所有效果表现。

## 五种模式
- Projectile（弹道）、SpawnAtTarget（落点）、Fullscreen（全屏）
- CustomPresenter（自定义）、CardCollision（对撞）

## 抽卡演出
spawn → staging → 翻面 → 停留 → 展开 → 落入槽位

## 攻击演出
攻击方前冲 → 目标抖动 → Impact特效 → 结算伤害

## 法术演出
飞展示位 → 翻面 → 弹道/全屏 → 命中 → 飘字反馈

## 配置入口
VFXConfigSO → spellPresentation / triggerPresentation / deployPresentation
