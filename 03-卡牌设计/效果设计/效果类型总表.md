# 效果类型总表

> 基于 ScriptableEffect 系统，所有效果通过 ScriptableObject 数据驱动。

## 三大效果生命周期

- **OneShotEffect**：单次触发。用于派遣、法术结算、天气预测、伤害、抽牌、治疗等。
- **TriggeredPersistentEffect**：持续监听事件。用于妖怪、设备在场效果和已激活御术的监听。
- **AuraEffect**：持续存在，脏标记刷新。用于光环、阵列范围、天气加成等。

## 常用 ActionSO

| 动作 | 说明 |
| --- | --- |
| DealDamage | 造成普通伤害。 |
| ElementalDamage | 造成指定元素伤害，并交给元素反应系统判定。 |
| DrawCards | 抽牌。 |
| AddAttack/AddHealth | 增减攻击或生命。 |
| GrantKeyword | 赋予词条，如疾袭、掩护、护甲、机械。 |
| WeatherAction | 预测天气、清除天气或立即改变天气。 |
| IfCondition | 条件分支。 |
| SealUnit | 封除单位，放入双方共用的公共封存卡组。 |
| RecruitUnit | 从公共封存卡组随机征召单位；征召者获得控制权。 |
| CorruptUnit | 腐化单位。 |

## 首版限制

- 御术只做暗置反制，不做每回合收益引擎。
- 天气不是卡牌类型，只是效果。
- 召唤物不再有 Token 特殊身份；通过效果使妖怪入场统一使用“召唤”；默认第二阵列最右边，满员则失败；克隆入场同样使用召唤。
- 固定召唤物统一为叶灵，基础身材1/1。母牌只写数量和明确授予的附加效果；完整定义见[子卡牌设计](../子卡牌设计/README.md)。现有卡牌的动态克隆和蜕变形态分别登记，不作为第二种固定召唤物。

## 本轮设计所需效果（不代表已实现）

- 设备部署、扣减防御力、摧毁，以及设备在场光环。
- 机械关键词在法术选择妖怪目标时的过滤，不能扩展成所有效果免疫。
- 移除反应状态：按状态分类批量移除，排除其他负面和正面效果。
- 下一次伤害修正：群体伤害按队列逐目标处理，首个符合条件的条目消耗修正。
- 费用效果：支付前应用、单来源不因刷新叠加、按回合或使用次数到期。

## 当前设计约束（2026-09-06）

- 不设计妖怪主动技能、是否执行的可选效果、当前法力回复或控制权交换。
- 指向性法术与派遣最多指定一个目标；附加目标由随机或相邻范围自动确定。
- 直接致死动作使用消灭；扼制使用动词模板；效果抽牌区分于正常规则抽牌。
- 子卡法术独立结算天气条件。父效果负责生成实例，不在父卡结算时替换子法术的天气分支。
- 当前ActionSO表只说明既有结构；新目标流程、子卡数据与事件约束需要后续按设计实现，不因写入本文就标记完成。
