# 卡牌类型体系

## 统一牌种
| 类型 | 说明 | 设计备注 |
| --- | --- | --- |
| 选手 | 每副卡组1张，代表玩家身份和生命；初始及基础最大生命按牌面读取，可具有常驻能力。 | 原“英雄”。代码可后续由 CardType.Hero 迁移为 CardType.Player。 |
| 妖怪 | 可派遣到战场的主要单位。 | 原“使徒/支援”合并。 |
| 法术 | 从手牌打出并结算的一次性效果，可含限时数值修正或有明确时点的一次性延迟结算。 | 可包含天气效果，但不存在“天气牌”类型。 |
| 御术 | 暗置反制牌。玩家回合支付费用激活，满足监听条件后触发。 | 原“咒术/Hex”。持续引擎不再归为御术。 |
| 设备 | 可部署，只有防御力，不能攻击或移动。 | 独立牌种，不属于妖怪或机械造物；详见《设备牌设计》。 |
## 妖怪牌细分

“妖怪牌”是可派遣上场的妖怪大类（包含机械造物，不包含设备）；其细分描述单位的来源，不表示它必须为人类社会承担某种功能。

| 细分   | 来源定义                                                    | 规则与设定边界                                                   |
| ---- | ------------------------------------------------------- | --------------------------------------------------------- |
| 兽灵   | 在自然环境中繁衍并经长期演化形成的妖怪谱系。元素器官、特殊行为和现代城市适应性都应能追溯到祖先特征与选择压力。 | 属于妖怪。当前澄曜区与澜桥区常规生物妖怪档案归为兽灵；赞助商机械造物单独归类；“像器物”“亲近居民”或名称带“灵”不改变其谱系归属。 |
| 物灵   | 无生命物体在特定条件下妖怪化后形成的个体或谱系。常见小型物体更容易发生妖怪化，但不是所有旧物都会成为物灵。   | 属于妖怪。后续新增时必须说明原物、妖怪化条件与是否能够繁衍，不得只凭外观判定。                   |
| 恶灵   | 由长期积累的负面能量形成、或被其彻底改变的高危险妖怪。现有研究不足，分类仍可能调整。              | 属于妖怪。不能把“凶猛”“有毒”或与人冲突的普通兽灵笼统归为恶灵。                         |
| 机械造物 | 由企业、研究机构或个人制造的作战、竞赛或通用机器人，多数具有金元素适配。                    | 属于妖怪，自带固定关键词“机械”：本妖怪不能被法术牌指定为妖怪目标。参与所有妖怪计数与事件；设备不属此类。                  |

### 兽灵设定原则

- 先说明生态位、食性、繁衍与行为，再说明它和居民偶然形成的关系。
- 不为每个物种安排职业、公共服务或产业用途；能够被观察、驯养或利用，不等于那是其演化目的。
- 演化解释采用“祖先特征—环境压力—适应结果”的自洽链条。元素可以参与选择，但不能用“因为有魔力”代替全部过程。
- 民间传说允许与科学解释并存；传说体现地方居民如何理解妖怪，不自动等同于客观真相。


## 单位定义

单位指战场上的妖怪（含机械造物）与设备，不包含选手；“妖怪”不包含设备。不限定牌种的目标包含选手、妖怪与设备，具体选择仍受阵列及牌面条件限制。

## 御术规则

- 御术从手牌拖拽使用时视为激活，立即支付费用。
- 激活后的御术以激活状态返回手牌并暗置监听。
- 御术默认在敌方回合满足条件时触发一次，触发后进入弃用状态，不再监听；特殊生效回合须明写。卡面直接写触发条件和结果，不加“下一次”。
- 多个御术同时满足条件时，按激活顺序结算。
- 御术不是持续引擎；持续光环或每回合收益应由妖怪或设备的在场效果承载。

## 天气效果规则

天气不是牌种。卡牌类型仍为妖怪、法术或御术，效果文本中可以写“预测天气为雨天”“清除当前天气”“将天气改变为艳阳天”。

## 效果文本的统一依据

- 阵营、实体、选手和玩家行为的指代，以及法力槽、限时增益、延迟结算和触发回合，统一遵循《卡牌文本规范》。
- 触发型在场效果默认只在我方回合触发；需要在敌方回合或双方回合触发时须明写。持续光环不因该触发默认值而在敌方回合失效。
- 赋予单位一项效果表示赋予持久能力；“回合结束时，对其造成2点伤害”则是原卡牌预约的一次性延迟结算，不能写成赋予单位持久能力。

## 机械的目标限制

- 机械造物属于妖怪，自带“机械”。妖怪数量、出牌顺序、死亡、移动、群体增益均正常计入机械造物。
- 机械：本妖怪不能被法术牌指定为妖怪目标。
- 妖怪目标：法术效果明确要求选择“妖怪”时所指定的目标；对友方和敌方的法术均适用，手牌中的妖怪牌被法术明确选中也属于此限制。
- “对一个妖怪……”不能指定机械造物；“对一个目标……”未要求妖怪目标，不受机械限制。“对所有敌方妖怪……”不指定目标，也不受机械限制。
- 妖怪的派遣、设备、御术和普通攻击不受机械的法术目标限制；仍需满足各自的合法目标条件。
- 机械是固定自带关键词，固定指每张机械造物的基础配置；不新增不可移除规则，腐化等移除关键词的效果仍按原规则执行。

## 指向行为与当前能力范围

法术分指向性与非指向性两种使用行为；前者最多指定一个目标，后者直接打出并自动结算。妖怪派遣效果同样最多指定一个目标；随机、相邻和范围效果不额外指定。当前不使用妖怪主动技能，也不使用控制权交换效果。详细流程见[卡牌使用与目标选择](../02-玩法设计/卡牌使用与目标选择.md)。
