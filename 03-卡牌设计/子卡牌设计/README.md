## 使用规则

- 子卡维护完整的费用、元素／伤害元素、基础属性及效果。母牌只写生成名称、数量和明确的附加效果，不重复维护子卡的完整效果。
- 叶灵基础1/1。母牌写“召唤1个叶灵”；加攻、加生命、护甲、掩护及授予亡语是生成后附加的效果，不另建同名不同基础数据的叶灵。
- 母牌授予叶灵的引号内能力，“本妖怪”指获得能力的叶灵；若引用母体，明确来源名称或关系。
- 子法术按自身打出时的天气结算。生成沃土精华时是否雨天，不决定它以后提供的增益。
- 新建独立文档不等于实现数据已创建；本次叶灵的基础费用定为1、元素定为木，作为回手后派遣及元素交互的设计值。
