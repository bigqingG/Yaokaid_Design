# 叶灵

| 字段 | 设计 |
| --- | --- |
| 设计ID | SUB_MON_001 |
| 牌种 | 妖怪 |
| 元素 | 木 |
| 基础费用 | 1 |
| 基础身材 | 1/1 |
| 基础关键词 | 无 |
| 基础效果 | 无 |
| 构筑 | 不能直接加入初始卡组，由卡牌效果召唤。 |

卡面统一写“召唤1个叶灵”。默认进入第二阵列最右边的合法空位，满员则无法召唤；不触发派遣。数量不足的召唤按剩余空位依次处理。

叶灵属于友方／敌方妖怪计数，正常参与攻击、移动、消灭与亡语。被返回手牌后按费用1派遣，明确施加的费用修正另行计算。

掩护、护甲、额外身材和亡语由母牌明确授予，属于附加效果。穰穰君授予的亡语引用生成该叶灵的穰穰君，不能误写为叶灵为自己成长。

来源与生成附加效果见[子卡牌索引](../README.md)。
