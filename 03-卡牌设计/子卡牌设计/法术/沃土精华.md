# 沃土精华

| 字段 | 设计 |
| --- | --- |
| 设计ID | SUB_SPELL_001 |
| 牌种 | 法术 |
| 费用 | 0 |
| 使用行为 | 指向性，只指定一个友方妖怪。 |
| 元素伤害 | 不造成伤害，不触发元素反应。 |
| 构筑 | 不能直接加入初始卡组。 |
| 来源 | 归根入土（WHO_010），每次生成2张加入手牌。 |

**效果：使一个友方妖怪获得+1/+1。若是雨天，改为+2/+1**

雨天条件由沃土精华在自身结算时判断。晴天生成、雨天打出时为+2/+1；雨天生成、晴天打出时为+1/+1。两张沃土精华分别独立使用，不继承母牌生成时的天气判定。

指向妖怪的法术不能指定具有“机械”的机械造物。目标获得的数值增益未写期限，按永久增益规则处理。
