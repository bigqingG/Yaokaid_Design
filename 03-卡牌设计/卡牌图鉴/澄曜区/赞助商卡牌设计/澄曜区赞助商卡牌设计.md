**地区：澄曜区**
**状态：v6 卡面文本精简版（2026-09-12）**
**用途：记录两家赞助商的现行卡池及玩法。**

文案遵循《卡牌文本规范》。机械造物属于妖怪，自带“机械”；设备是独立牌种，不属于妖怪或机械造物。设备基础规则见《设备牌设计》。表中防御力只用于设备，身材只用于妖怪。

## 3. 共通规则与协同

### 3.1 法力槽与费用

- “额外获得1点法力槽”只使最大法力+1，当前法力不变。例如1/3变为1/4，我方下回合正常增槽并补满后为5/5。
- 正常回合增长最多到12；效果增槽可超过12，之后正常回合不再增槽，但仍按现有槽数补满法力。
- 费用增减统一写“获得费用±X”。下一张牌的减费在支付前生效，只用于该次支付；本回合未用完则到期。未写本回合期限的下一张牌减费保留至使用。
- 防御力、费用和各牌数值为当前设计值，后续以对战测试调整；三选一获取不是无限提高强度的依据。

### 3.2 机械与设备边界

- 机械造物参与妖怪计数，可触发“友方妖怪被消灭”“友方妖怪移动”等事件，也受未指定目标的群体妖怪效果影响。
- 稳定母线、始发检点、进路开放、快速换端、动车组重联等法术明确选择妖怪，不能指定仍有“机械”的机械造物；全功率并网不指定目标，可以强化火或金元素的机械造物。
- 调车虎机、RBC及应急抢修车的效果不是法术指定，可以作用于符合条件的机械造物。
- 黑启动方案和黑启动单元检查妖怪数量时，计入机械造物，不计入设备。
- 孤岛运行、全域协调、RBC、CTCS-3为设备，有防御力，没有攻击力，不能攻击、反击或移动。设备不享受仅面向妖怪的增益。

### 3.3 与澄曜区常规卡的协同

| 组件 | 协同方式 |
|---|---|
| 日轮高悬／烈日当空＋日照捕获 | 先进入艳阳天，再获取额外法力槽。 |
| 搏命熊＋裂炉吼 | 搏命熊攻击伤害己方选手，触发裂炉吼；超载许可仅提高攻击并自伤妖怪，不直接触发裂炉吼。 |
| 弱点显影＋元素伤害 | 对标记目标的元素伤害增强；无需对方先有护甲。 |
| 全功率并网＋火／金妖怪 | 强化符合元素条件的妖怪；下一次元素增伤只影响伤害队列首个符合条件的目标。 |
| 霓火茧／火灶灵＋CTCS-3 | 低费出牌接入第二、第三张牌奖励。 |
| 铁芯蟾＋调车虎机／进路开放 | 调整阵列；蜕变仍由天气变化触发。 |
| 电弧旁路＋全域协调／跃弧犬 | 敌方回合增槽也能触发收益；全域协调减费可用于之后的出牌。 |
