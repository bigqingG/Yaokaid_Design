## 一、法力价值模型（Mana Value Model）

### 1.1 基础公理

**1法力 = 2点属性价值（Attribute Value, AV）**

属性价值 = 攻击力 + 生命值（对妖怪牌而言）

### 1.2 标准身材曲线（Vanilla Stat Curve）

无任何效果的"白板"妖怪，其标准身材如下：

| 费用 | 标准身材 | 属性和(AV) | 公式验证 | 定位 |
|:---:|:---:|:---:|:---:|---|
| 1 | 2/1 或 1/2 | 3 | 2×1+1=3 | 前期过渡 |
| 2 | 2/3 或 3/2 | 5 | 2×2+1=5 | 早期主力 |
| 3 | 3/4 或 4/3 | 7 | 2×3+1=7 | 中期核心 |
| 4 | 4/5 或 5/4 | 9 | 2×4+1=9 | 转折点 |
| 5 | 5/6 或 6/5 | 11 | 2×5+1=11 | 后期主力 |
| 6 | 6/7 或 7/6 | 13 | 2×6+1=13 | 终结者 |
| 7 | 7/8 或 8/7 | 15 | 2×7+1=15 | 超模终结 |
| 8+ | 每费+2属性 | — | — | 稀有度补偿 |

**通用公式**：标准属性和 = 2 × 费用 + 1

### 1.3 高费效率递增原则

为鼓励游戏进入后期，高费卡牌的属性效率略高于低费：

| 费用段 | 效率系数 | 说明 |
|:---:|:---:|---|
| 1-2费 | ×1.0 | 基础效率，保证前期不卡手 |
| 3-4费 | ×1.05 | 中期略优 |
| 5-6费 | ×1.1 | 后期优势 |
| 7费+ | ×1.15 | 终结牌超模 |

> 实际应用：计算标准身材时先按基础公式，再乘以效率系数，最后取整。

## 二、效果价值量化表（Effect Value Table）

所有非身材效果均折算为"法力价值"（MV, Mana Value），1 MV = 2 AV。

### 2.1 基础效果价值

| 效果 | 法力价值(MV) | 备注 |
|---|:---:|---|
| 造成1点伤害（任意目标） | 1.0 | 指向伤害 |
| 造成1点伤害（随机目标） | 0.7 | 随机性折扣 |
| 造成1点伤害（全体） | 0.5/目标 | AOE单位价值递减 |
| 恢复1点生命（单位） | 0.5 | 治疗效率为伤害的一半 |
| 恢复1点生命（选手） | 0.4 | 选手生命价值略低 |
| 抽1张牌 | 2.0 | 卡牌本身价值+资源价值 |
| 获得1点法力（本回合） | 0.8 | 临时法力有时间价值折扣 |
| 获得1点法力（永久上限） | 1.5 | 永久法力增长价值高 |
| 召唤1/1妖怪 | 1.0 | 等于1费白板的一半价值 |
| 召唤2/2妖怪 | 2.0 | — |
| 召唤X/X妖怪 | X | 按标准身材折算 |

### 2.2 关键词价值

| 关键词 | 法力价值(MV) | 触发条件折扣 | 备注 |
|---|:---:|:---:|---|
| 疾袭 | +1.0 | — | 上场即可行动，节奏价值高 |
| 掩护 | +0.5 | — | 保护价值，受站位限制 |
| 护甲X | +0.5×X | — | 每点护甲抵挡1战斗伤害 |
| 先发 | +0.3 | — | 可直接放前排，略省移动费 |
| 扼制（施加） | +1.0 | — | 让敌方单位废一回合 |
| 腐化（施加） | +1.5 | — | 移除所有增益/词条/在场效果 |
| 蜕变 | +1.0 | 需条件触发 | 形态变化的灵活性价值 |

### 2.3 触发类效果折扣

同一效果，根据触发方式不同应用不同折扣系数：

| 触发方式 | 折扣系数 | 说明 |
|---|:---:|---|
| 打出法术（当前不含妖怪主动技能） | ×1.0 | 完全可控 |
| 派遣时触发 | ×0.7 | 仅一次，需打出该牌（v2.1修正：原0.8偏高，导致派遣效果卡普遍超模） |
| 亡语触发 | ×0.7 | 需死亡，时机不可控 |
| 在场每回合触发 | ×2.0 | 持续收益，按期望存活2回合计算（v2.1修正：原1.5低估了持续效果价值） |
| 条件触发（天气/元素/场面） | ×0.5 | 有条件才生效 |
| 随机目标 | ×0.7 | 不可控 |
| 对手可反制 | ×0.8 | 存在互动窗口 |

### 2.4 元素反应价值

| 反应 | 基础价值(MV) | 持续/即时 | 说明 |
|---|:---:|---|---|
| 点燃 | 1.5 | 持续2回合 | 共2点伤害，分摊后价值 |
| 熄灭 | 1.0 | 持续2回合 | 封锁火元素反应 |
| 吸收 | 1.0~2.0 | 即时 | 取决于造成伤害量，按50%折算 |
| 淤塞 | 1.5 | 持续2回合 | 暂时沉默在场效果 |
| 劈斩 | 0.5 | 即时 | 穿甲2点， situational |
| 熔蚀 | 1.0 | 下次攻击 | 攻击-1+破甲1 |
| 根裂 | 0.5 | 下次受伤 | 受伤+1，需后续伤害配合 |

> 元素反应为概率触发，实际期望价值 = 基础价值 × 触发概率。
> 设计卡牌时，若效果文本写明"造成X元素伤害"，应按平均触发概率（约40%）计算期望价值。

### 2.5 天气联动价值

| 天气相关效果 | 法力价值(MV) | 备注 |
|---|:---:|---|
| 预测天气（1回合） | 0.5 | 天气双方受益，价值打折 |
| 预测天气（2回合） | 0.8 | — |
| 清除当前天气 | 1.0 | 反制价值 |
| 立即改变天气 | 1.2 | 强力节奏控制 |
| "若是艳阳天/雨天，效果增强" | 增强部分×0.5 | 条件触发折扣 |

## 三、卡牌总价值计算公式

### 3.1 妖怪牌价值公式

```
卡牌总价值(MV) = 身材价值 + 效果价值
身材价值(MV) = (攻击力 + 生命值) / 2
效果价值(MV) = Σ(各效果基础价值 × 触发折扣系数)
```

### 3.2 费用校验

```
合理费用区间 = 卡牌总价值(MV) ± 0.5
超模判定：卡牌总价值 > 费用 + 1.0 → 超模，需削弱
亏模判定：卡牌总价值 < 费用 - 1.0 → 亏模，需增强
```

### 3.3 稀有度强度梯度

稀有度不直接决定强度，但允许更高的"设计复杂度"和"上限潜力"：

| 稀有度 | 强度允许区间 | 设计复杂度 | 拷贝数限制 |
|---|:---:|---|:---:|
| 一般 | 标准值 ±0.3 | 单机制 | ≤4 |
| 稀有 | 标准值 ±0.5 | 单机制+条件增强 | ≤3 |
| 罕见 | 标准值 ±0.7 | 双机制联动 | ≤4 |
| 史诗 | 标准值 ±0.8 | 三机制/抉择 | ≤1 |
| 传说 | 标准值 ±1.0 | 卡组核心/特殊胜利 | ≤1 |

> 关键原则：稀有度 = 复杂度和独特性，不等于无脑超模。一般牌也应该能进入构筑。

## 四、法术牌与御术牌数值规范

### 4.1 法术牌价值公式

```
法术总价值(MV) = 效果价值总和
合理费用 = 法术总价值 × 0.8（法术无身材，效率略高）
```

### 4.2 御术牌价值公式

```
御术总价值(MV) = 触发效果价值 × 0.6（暗置反制，需对手配合）
合理费用 = 御术总价值
```

> 御术因为需要对手触发特定条件，价值折扣更大；但反制成功时的节奏价值高。

## 五、地区特色与数值偏向

每个地区有明确的数值偏向，确保卡组风格差异化：

| 地区 | 主元素 | 核心机制 | 数值偏向 | 天气倾向 |
|---|---|---|---|---|
| 澄曜区 | 火/金 | 自伤换节奏、爆发 | 高攻低血、伤害效率+10% | 艳阳天 |
| 青棠区 | 木/水 | 铺场、治疗、复制 | 高血低攻、治疗效率+20% | 雨天 |
| 沃衡区 | 土/木 | 召唤物、群体成长 | 召唤物效率+15%、buff效率+10% | 艳阳天/雨天 |
| 澜桥区 | 水/金 | 控制、回收、手牌运营 | 控制效果效率+15% | 雨天 |
| 砚岭区 | 土/金 | 防守、反击、护甲 | 护甲效率+20%、防守反击 | 平常天 |
| 霜港区 | 金/水 | 机械、装备、重型单位 | 高费单位效率+15% | 平常天/雨天 |

### 5.1 地区数值偏向的应用

地区偏向是"设计指导"，不是"硬性加成"。具体表现为：
- 该地区的卡牌更倾向于使用某类效果
- 该地区的标准身材可以微调（如火系偏攻击、木系偏生命）
- 该地区的联动卡更多围绕核心机制

## 六、平衡性红线（Hard Limits）

以下为绝对不可突破的数值红线：

### 6.1 前期节奏红线

| 限制项 | 红线值 | 原因 |
|---|:---:|---|
| 1费妖怪最高攻击力 | 2 | 防止1费抢血过快 |
| 2费妖怪最高攻击力 | 3 | — |
| 1费法术最高伤害 | 2 | 防止1费解一切 |
| 2费法术最高伤害 | 3 | — |
| 1费可获得的法力 | 1（临时） | 防止法力跳费过快 |

### 6.2 卡牌效率红线

| 限制项 | 红线值 |
|---|:---:|
| 单卡总价值/费用比 | ≤1.5 |
| 抽牌效率（每费抽牌数） | ≤0.5 |
| AOE伤害效率 | 单体伤害的60% |
| 治疗效率 | 伤害效率的50% |

### 6.3 OTK防护

- 任何单回合斩杀组合，所需组件≥3张
- 任何"直接伤害选手"的效果，单卡最高≤4
- 7费前不允许稳定OTK

## 七、数值设计工作流

### 7.1 新卡设计流程

```
1. 确定牌组角色（启动/引擎/收益/干扰/终结/怪构筑）
2. 确定费用档位
3. 按标准身材曲线分配基础属性
4. 按效果价值表分配效果预算
5. 计算总价值，校验费用合理性
6. 标注风险等级与反制点
7. 填入设计骨架表
```

### 7.2 现有卡审计流程

```
1. 提取卡牌的费用、身材、所有效果
2. 按效果价值表逐项折算MV
3. 计算总价值与费用的偏差
4. 标注超模(>费用+1) / 合理 / 亏模(<费用-1)
5. 超模卡给出削弱建议，亏模卡给出增强建议
```

## 九、版本迭代与数值调整

### 9.1 调整原则

1. **优先调整数值，不轻易改机制**：攻击力/生命值/费用的微调优先于效果重做
2. **一次只改一个变量**：避免多重调整导致无法归因
3. **记录调整历史**：每次调整记录原值、新值、原因、预期效果
4. **观察期≥1周**：调整后至少观察一个版本周期再决定是否继续

### 9.2 调整幅度参考

| 调整类型 | 小幅 | 中幅 | 大幅 |
|---|:---:|:---:|:---:|
| 攻击力 | ±1 | ±2 | ±3 |
| 生命值 | ±1 | ±2 | ±3 |
| 费用 | — | +1 | +2 |
| 效果数值 | ±1 | ±2 | 重做 |

## 附录A：常见卡牌价值速算

### A.1 派遣伤害妖怪

```
3费 3/3 派遣：造成2点伤害
身材价值 = (3+3)/2 = 3.0 MV
派遣效果 = 2伤害 × 1.0 × 0.7(派遣折扣) = 1.4 MV
总价值 = 4.4 MV
费用3 → 超模1.4，需削弱（建议身材改为2/3或伤害改为1）
```

### A.2 亡语召唤妖怪

```
2费 2/2 亡语：召唤1/1
身材价值 = (2+2)/2 = 2.0 MV
亡语效果 = 1.0 MV × 0.7(亡语折扣) = 0.7 MV
总价值 = 2.7 MV
费用2 → 合理（超0.7在允许范围内）
```

### A.3 天气增强法术

```
2费法术：造成2点伤害。若是艳阳天，改为3点。
基础效果 = 2 × 1.0 = 2.0 MV
天气增强 = (3-2) × 1.0 × 0.5(条件折扣) = 0.5 MV
总价值 = 2.5 MV
法术效率系数0.8 → 合理费用 = 2.5 × 0.8 = 2.0 → 合理
```
