# 澄曜区卡牌补充方案：60张完整卡池

> 日期：2026-09-08  
> 版本：天气与打造赞助主轴修订版  
> 文本规范同步：2026-09-13，无歧义时省略“本妖怪”，卡面效果末尾不加句号
> 口径：第二版正式定稿22张 + 新增38张 = 60张常规地区卡。  
> 基线：现有22张保留；新增部分为本次重做的完整设计方案，数值需对战验证。  
> 编号：CYS_001—CYS_022为既有；CYS_023—CYS_060为新增。  
> 首批目标：建立天气 → 打造赞助 → 使用赞助服务 → 兑现澄曜的自伤、反应和阵列进攻。  
> 60张不包含选手、赞助服务卡、赞助商专属机械造物、蜕变形态和克隆实例。

## 一、现有规则与首批设计目标

### 1. 打造是现有核心玩法

[核心玩法概述·关于赞助商](../00-项目总览/核心玩法概述.md)已明确：选择主、副地区时选择主地区对应的赞助商；“打造一张赞助牌”从该赞助商牌库三选一，选择一张加入手牌。

[澄曜区赞助商卡牌设计](../03-卡牌设计/卡牌图鉴/澄曜区/赞助商卡牌设计/澄曜区赞助商卡牌设计.md)也明确：两家赞助商的服务卡不进入常规卡组，通过“打造一张赞助”等效果获取。现有两家赞助商分别有15张服务卡，机械造物另列。

《卡牌文本规范》目前没有独立“打造”小节，《效果类型总表》也没有单列完整的打造流程。这是规则分散与文案条目尚未集中，不表示打造尚不存在。常规卡设计必须给玩家提供足够的打造来源，否则所选赞助商的服务卡池难以进入对局。

### 2. 第二版22张的长处与需要补足的部分

现有定稿已建立明确的晴天、自伤、元素反应和战斗交换身份。17张主卡的效果直接提及天气，符合首批以天气为主要体验的方向。补充应延续这种密度，并把赞助获取与使用接到这些现有事件上。

| 现有结构                   | 首批需要补足的环节                | 本次处理                                 |
| ---------------------- | ------------------------ | ------------------------------------ |
| 22张正式卡中没有“打造”效果        | 赞助商有服务池，但本区这些常规卡本身没有获取入口 | 新增11张打造来源，覆盖不同费用与触发方式                |
| 火灶灵、霓火茧、铁芯蟾、火取等已明确依赖天气 | 需要增加天气使用方式，而不是稀释主轴       | 在既有短晴预测之外，增加治疗＋长晴预测、强力改天＋打造          |
| 锻金咚、裂炉吼、焰舞沙魈、搏命熊形成自伤链  | 自伤应既能换攻击，也能换赞助选择         | 赫噜噜连接“晴天＋选手受伤＋打造”                    |
| 曜金拉恩奖励金元素反应            | 反应除了直接伤害，也应带来资源决策        | 磷须的劈斩打造、火候正好的火反应打造                   |
| 冷酷蜥、逆焰鬼等保留特殊构筑         | 特殊构筑可以继续存在，并参与首批主轴       | 九烬连接死亡与打造，璨壳连接晴天移动与打造                |
| 地区强调快节奏、连续出牌           | 连续出牌需要来自具体来源与用途          | 吞芒奖励打造；瞬目、折光伶奖励使用；赤蹑、镜魈、昼不落兑现天气与使用条件 |
| 常规法术原本只有两张天气法术         | 解场、保护与天气、赞助应共同工作         | 仍补足单体解场、群体伤害、治疗和暗置保护                 |

本版以**天气与打造赞助为首批共同主轴**。自伤、反应、移动、死亡与连击是接入主轴的不同路线。保留少量无条件工具，用于启动和处理场面，不把这些工具扩展为与首批目标无关的大量独立体系。

### 3. 原定稿的配合口径

- 福祸相依默认在敌方回合触发一次，不能计入我方回合的锻金咚自伤连段；新增赫噜噜明确承接我方回合的自伤打造。
- 曜金拉恩的金元素反应按现行表指金攻击木的“劈斩”；火攻击金的“熔蚀”属于火元素反应。
- 打造赞助不会自动抽我方卡组里的牌，也不等于已经打出赞助牌。普通抽牌、检视、克隆与打造分别处理。
- 先发允许前排派遣，疾袭允许入场当回合行动；移动与攻击仍消耗法力，前排保护和掩护仍有效。
- 铁芯蟾只占1张种数，焚芯蟾与流芯蟾不单独计入60张；赞助服务池的30张现有牌也不重复计数。
- 既有名称按第二版正式稿使用；新增名称保留当前文件中的蹦焰砂、披铆背、响响腹等用户修改。

## 二、卡池结构

### 1. 天气与赞助覆盖

| 统计口径 | 既有22张 | 新增38张 | 完整60张 |
|---|---:|---:|---:|
| 效果直接提及天气／晴雨条件 | 17 | 28 | 45 |
| 效果直接涉及赞助获取／使用 | 0 | 19 | 19 |
| 其中：能够打造一张赞助牌 | 0 | 11 | 11 |

| 至少直接关联上述一个主轴 | 17 | 34 | 51 |

以上是不同卡牌种数，行与行存在交集，不能相加当作总数。完整卡池45张直接关联天气，占75%；51张直接关联天气或赞助，占85%。不把通用火元素伤害天然受天气影响的卡再额外算作“卡面天气牌”。

新增只有蹦焰砂、披铆背、开道、寸步不让四张纯基础配套牌；它们分别提供选手自伤、前排保护、直接解场和伤害减免，支持主轴的启动与存活。

## 三、打造文案与事件口径

### 1. 已有规则

- 统一卡面写作：**打造一张赞助牌。**
- 获取来源是我方所选赞助商的服务卡池。选择由主地区决定的赞助商；副地区卡上的打造也使用该玩家已经选择的赞助商，不另设第二家。
- 三选一决定加入手牌的牌，不是在完整服务池中任意指定一张。
- 打造得到的牌加入手牌，随后依其自身费用、类型、目标与天气条件正常使用。不是免费施放、部署或激活。
- 法术和御术自身没有元素身份；元素伤害仍须在服务牌或地区卡的伤害文本中明确写出。

### 2. 本补充方案采用的事件细化

下面用于让新增卡面可以明确结算，是本方案对事件与来源的细化，不声称这些细节已经全部写入全局规则或代码。

| 措辞 | 本方案含义 | 不包含的事件 |
|---|---|---|
| 我方打造赞助牌后 | 一次三选一完成，所选服务牌成功加入手牌后，记录一次打造完成事件 | 展示三个候选不算三次；普通抽牌、检视与克隆不算打造 |
| 我方打出赞助牌后 | 我方实际使用一张服务池定义的赞助牌；法术打出、御术支付激活、设备部署各计一次 | 打造入手、御术之后被动触发、设备之后被动发放收益 |
| 本回合打出过赞助牌 | 检查本回合已发生的上述使用记录 | 不因为当前持有赞助牌、场上有设备或赞助商已选定就满足 |
| 打造……使其获得费用-1 | “其”指本次三选一选中并成功加入手牌的那一张牌 | 不降低三个候选、来源妖怪或本回合所有服务牌的费用 |

本方案的“赞助牌”按**服务池卡牌身份**判断，不要求额外记录“这一次是不是通过打造拿到”。合法克隆出的同款服务牌仍保留服务牌身份。两家赞助商另列的可构筑机械造物不因来自赞助商就自动满足这一“服务牌使用”条件；它们仍可通过妖怪、元素与移动事件参与配合。

打造中的候选选择属于手牌获取决策，不是再次指定战场目标。因此火候正好允许先指定一个敌方妖怪，随后在满足反应条件时完成已有的三选一；不增加第二次战场指向。自动触发打造也沿用这个选择流程，不变成点击妖怪发动的主动技能。

打造结果的减费未写期限时是持久费用修正；折光伶、以血为薪的“本回合下一张”是限时、一次支付修正。服务牌自己的晴雨分支在它实际打出／触发时判断，不能用打造时的天气永久替换服务牌原文。

候选是否允许同名、空服务池、满手牌和候选选择流程的完整异常处理，需要沿用并补齐通用打造实现；本方案不提供指定某张服务牌必然出现的保证。满手牌未成功加入所选牌时，本方案不发出“打造完成”收益事件。

## 四、命名与形象

沿用最新“第三版命名方向：妖怪 IP 感”，保留当前文件的38个名称。蹦焰砂、赤蹑突出步态，叮当颚、赫噜噜、响响腹突出发声与身体结构，折光伶、镜魈突出辨识行为，九烬与昼不落提供大妖记忆点。

新增妖怪仍按兽灵候选方向描述。卡牌中的打造是对战资源机制，不等于野生妖怪在生态上必须替公司工作、制造设备或承担都市岗位。每张“命名与形象”是新增美术和生态提案，不擅自写成已有正史或进化关系。

法术与御术继续采用行动短语、成语和仪式意象。白昼有约承接约定中的晴天与赞助选择，见好就收表现收住自伤并寻找后续服务，胜负未定体现敌方回合的一次交换带来新筹码。卡名不因加入打造就批量改成“某某匠、某某公司、某某工坊”。

## 五、新增38张完整设计

### 阅读约定

所有新增牌地区均为澄曜区；妖怪身材为攻击力／生命值，法术与御术元素及身材为“—”。关键词与基础效果上卡面，其他字段供策划阅读。

持续触发默认只在我方回合，御术默认只在敌方回合触发一次；每回合一次按各来源分别计数。妖怪默认第二阵列，先发允许前排；普通攻击默认1费，移动不能当作免费攻击。普通效果伤害不因来源妖怪为火元素而自动变成火伤。

### 两家赞助商如何改变同一套地区骨架

**扬子江光学电力公司**：打造时在现有候选里权衡峰谷调度的出牌衔接、弱点显影对低费受伤妖怪的处理、储能回充的后续槽位与全功率并网的终结。自伤打造能与需求响应接力，但额外法力槽不恢复当前法力。晴天核心更偏向场面处理、短时爆发和下回合资源准备。

**曜川高速铁路集团**：打造时权衡进路开放的移动、快速换端的延后回手、CTC的选牌与CTCS-3的出牌顺序收益。璨壳能把一次合法移动转为新的服务选择；折光伶奖励服务使用后派遣妖怪。晴天核心更偏向站位与连续出牌的安排。

每个玩家只使用其所选赞助商的服务池。不能把两家各自最理想的服务拼成一套“必然出现”的连段。三选一的选择结果有不确定性，卡组仍需保留无需某张特定赞助牌才能启动的来源和下限。

## 七、关键连段与结算核对

### 1. 白昼有约：先建立天气，再获取，再使用

假设我方选择光学电力公司，本回合尚未执行天气效果，拥有7点法力和合法前排位置：

1. 支付3费打出白昼有约，立即改变为艳阳天（1），随后打造一张赞助牌。
2. **若本次候选出现并选择峰谷调度**，它进入手牌。此时只是完成打造；在场吞芒能获得晴天的临时攻击奖励，瞬目与折光伶尚不因这一步触发。
3. 支付1费打出峰谷调度，发放下一张原始费用不低于3的牌费用-2。现在才满足“本回合打出过赞助牌”。
4. 派遣赤蹑，支付4−2=2费；晴天与赞助使用条件同时成立，赤蹑获得疾袭，并可凭先发进入第一阵列。
5. 再付1费攻击合法目标。合计3＋1＋2＋1＝7费。

这不是保证每次都能选到峰谷调度的标准起手。若拿到的是4费设备，就需要根据剩余法力和场面改变使用顺序。敌方第一阵列有单位时，赤蹑仍不能直接攻击选手。

### 2. 赫噜噜：自伤换服务，服务再换行动

假设当前为艳阳天，赫噜噜、裂炉吼已在场且本回合未触发。打出蹦焰砂，己方选手实际受到1点普通伤害：

- 裂炉吼按正式卡文获得晴天攻击成长。
- 赫噜噜完成一次打造。
- 打造成功不增加我方本回合的出牌张数；之后使用所选服务牌才增加一次出牌。
- 若瞬目也在场，它要等服务牌被打出后才成长。单次自伤不能直接让它得到奖励。
- 本回合再次受伤，已触发的赫噜噜不再打造；其他未触发来源仍分别按自身条件处理。

若改用以血为薪，它在晴天下提供妖怪费用-2。再打造并使用峰谷调度，有可能继续叠加费用修正，因此该组合要按现行“费用最低为0”和真实攻击法力检查，不能把一次触发上限当作所有减费都不叠加。

### 3. 璨壳：赞助服务推动移动，移动再带回选择

假设我方选择高铁集团，当前为艳阳天，璨壳已经在场，并有一个能合法移动、没有机械关键词的第二阵列友方妖怪：

1. 支付2费打出见好就收，打造赞助，并恢复己方选手2生命。
2. **若候选中出现并选择进路开放**，支付其1费，指定该妖怪，将其移动到第一阵列合法空位。
3. 璨壳因其他友方妖怪移动而再打造一张赞助牌，本回合不再重复打造。
4. 这段已支付3费；进路开放是效果移动，不再额外点一次普通移动，但也不让被移动妖怪立即攻击。
5. 若同时有RBC，它按自身规则奖励被移动妖怪；如果第一阵列没有合法空位，不能假定已经移动并发出两类收益。

璨壳产出的新服务仍需自行支付费用。多个璨壳会各自触发，应按多来源评估资源上限；不能因为每张有一次上限就声称总共只生成一张。

### 4. 胜负未定：长晴延伸到敌方回合

我方用余温未散恢复妖怪并预测艳阳天（2）。若当前为平常天，这段天气立即成为当前天气。另付2费激活胜负未定。

敌方回合，若一个敌方妖怪被消灭，御术触发一次，打造赞助牌；若此时仍是艳阳天，所选牌获得费用-1。这份未注明期限的折扣保留到之后正常使用，而不是自动恢复当前法力。

对手有机会通过天气效果争夺窗口。若触发时已经不再是晴天，仍打造但不减费。吞芒默认只在我方回合监听，不能因这次敌方回合的打造获得攻击力。御术产生选择不等于允许在敌方回合主动打出新获得的服务牌。

### 5. 火候正好：用天气提高反应机会，完成一次打造

火候正好明确造成4点火元素伤害。在合法目标、实际伤害与反应结算条件成立时：

- 火对木在艳阳天有点燃的天气优势；火对金的熔蚀概率受艳阳天提高。
- 确实以这段伤害触发点燃或熔蚀后，才打造一张赞助牌；不根据卡名、地区或目标阵营直接发奖。
- 打造三选一不是第二次战场目标指定，也不把本牌变成连续监听的法术。
- 非木、非金目标没有这两种反应，仍结算基础4点伤害。
- 焚芯蟾可放大这一火元素伤害；不能放大乘胜追击或落幕之前的普通伤害。

### 6. 镜魈与昼不落：晴天服务的不同终点

镜魈需要当前晴天和本回合使用过赞助服务，满足后召唤自身克隆。克隆默认第二阵列，且不触发派遣；不会因为同样处于晴天而无限复制。母体正常入场但第二阵列没有剩余空位时，不生成克隆。

昼不落沿用已经保住的第一阵列：在晴天且本回合用过赞助时，其他前排友方妖怪各临时加4攻，本体没有疾袭。假设天气此前已建立、先使用一张1费服务、不计外部减费，再派遣7费昼不落并让3只已有妖怪各攻击一次，这段预算为1＋7＋3＝11费。天气若还要本回合建立，费用与天气次数另计；若服务自带减费，则按实际修正重算。不能把群体加攻直接当作7费无站位要求的选手伤害。

## 八、数值与实现边界

### 1. 主要预算处理

打造提供三选一灵活性，不能当作零成本附赠。以现有数值框架的单次选牌约2 MV作首轮估算，派遣／亡语乘0.7，反复在场收益按预期存活回合评估；晴天或战斗条件影响兑现率。这个估值是设计起点，不是精确强度证明。

| 卡牌 | 预算处理 | 要比较的实际价值 |
|---|---|---|
| 铿锵仔 | 3费1/2：身材1.5＋先发0.3＋一次打造约1.4＝约3.2 MV | 为无条件打造交出场面身材，不能同时作为高效3/3骨干 |
| 响响腹 | 4费3/2：身材2.5＋亡语打造约1.4＝约3.9 MV | 延后资源，防止高身材再叠无条件三选一 |
| 跳铢 | 2费2/1，加晴天条件的一次打造 | 更便宜但条件更强、更脆，不替代无天气入口 |
| 赫噜噜 | 调为4费1/3 | 晴天自伤可反复产牌，必须给对手有效的清除窗口 |
| 璨壳 | 调为4费1/4 | 反复移动打造不能白拿2/5守场身材；前排满员会限制兑现 |
| 九烬 | 调为5费2/4 | 用弱身材支付死亡打造与晴天生成牌减费 |
| 呵烬 | 调为3费2/2 | 让晴天2点派遣补刀支付身材成本 |
| 烙尾巴 | 调为4费3/3、疾袭，晴天条件护甲1 | 将原高攻击预算转给天气战斗存活 |
| 白昼有约 | 3费，无妖怪身材 | 立即改天与一次打造组合，不附赠免费使用服务 |
| 乘胜追击／落幕之前 | 选手伤害上限分别4／3，均为普通效果伤害 | 不用火伤光环继续放大高效直伤收尾 |

披铆背保留2费2/2、先发、掩护。依严格MV加总约2.8，仍是一般卡预算边界例，需要比较其在双阵列中的实际防护价值。本方案没有将所有复杂卡标为数值公式严格通过。

### 2. 优先验证的组合

| 验证点 | 预期边界与重点 |
|---|---|
| 打造成功与赞助使用两个事件 | 获取不触发瞬目；使用不重复触发吞芒；候选三张不能变成三次打造 |
| 赞助御术与设备 | 御术支付激活、设备部署各计一次赞助出牌；之后的被动触发不再计出牌 |
| 两家服务池 | 根据所选赞助商取候选，不把对方服务或常规机械造物混入池中 |
| 赫噜噜＋以血为薪＋峰谷调度 | 记录真实自伤、生成与选择、减费叠加和攻击费用；不承诺7费前已排除所有稳定斩杀 |
| 多个赫噜噜／璨壳／九烬 | 每来源一次与多来源总收益分别记录；回手重打、克隆和触发上限重置需要实测 |
| 打造＋减费＋全域协调／CTCS-3 | 额外法力槽不补当前法力；服务使用与设备被动奖励不重复计事件 |
| 胜负未定与天气将散 | 以御术真正触发时的天气决定生成牌减费，不锁定激活御术时的天气 |
| 九烬与胜负未定的“其” | 只修正本次选中的服务牌；候选、来源与死亡对象都不吃该折扣 |
| 火候正好的反应奖励 | 根据实际伤害和反应票据发一次打造，不因为反应状态已有或目标已死亡就假造新反应 |
| 归焰凰＋烬中留名 | 两个独立来源可能各生成一个克隆；需核对增益、伤害值、费用修正继承与满手牌行为 |
| 白昼有约＋日照捕获等天气服务 | 打造可拿到天气服务，但不能忽略每个自己回合最多一次天气效果的规则而连续执行两次改天 |
| 生成数量与手牌上限 | 首批的目标是提供足够选择；仍需测试11种来源在不同配比下是否形成过量资源和过长选牌时间 |

这些是待执行的对战和事件验证，不是游戏代码已实现或平衡测试已通过的报告。新效果可用现有单次效果、在场触发、条件检查与修正结构表达，但打造完成、服务牌身份、服务出牌等事件要确认实现对应关系。
