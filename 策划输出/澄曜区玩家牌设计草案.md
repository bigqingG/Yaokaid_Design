# 澄曜区玩家牌设计草案

> 版本：v0.3｜2026-09-11  
> 牌种正式名称：选手（玩家牌）  
> 状态：C3 候选人物与卡牌设计，尚未进行对战测试。  
> 规模：12张，覆盖现有地方索引中的6个地方单元，每地2人。

## 一、设计基线

选手开局固定存在，生命归零即败北。初始生命和基础最大生命由各张选手牌决定，不再统一为20。以生命值、触发门槛、收益大小与触发时点共同平衡常驻能力；能力在整局持续有效，不设置整局次数配额。触发回合默认指我方，有限次能力统一写“每回合一次”；林照按每次攻击触发，顾栎明确在敌方回合触发，方衡以无能力、高生命作为对照。

### 本次参考与取舍

参考用户提供的《Player牌设计草案.md》：采用“30血作为测试中点、27—33血分档”“高生命白板”“轻量常驻被动”“通过行为而非单一元素标签区别构筑”等思路。这些血量是首测设计值，并非证明能力之间已经平衡，也不是以后所有选手不可突破的硬性区间。

参考文件还建议40张构筑、起手额外查看及首次打造赞助等独立系统改动。本次调整范围是选手生命与效果，构筑沿用当前30张含1张选手，即1张选手加29张其他牌；参考文件中的一次性整局能力不采用。

以现行项目规则校正参考示例：火灶灵目前为1费1/1，并非参考文件示例中的2费2/3；派遣不等于召唤，普通妖怪派遣当回合通常不能攻击。因此不照搬低费妖怪派遣后只在当回合加攻作为通用新手能力。

依据现行文件：

- [胜负条件](../../../02-玩法设计/胜负条件.md)：选手的初始生命按牌面读取，生命归零判负。
- [卡组构筑规则](../../卡组构筑规则.md)：保持30张含1张选手及主副地区规则。
- [战场系统](../../../02-玩法设计/战场系统.md)：选手位于第二阵列中央；普通攻击仍受前排保护等限制。
- [卡牌文本规范](../../../02-玩法设计/卡牌文本规范.md)、[资源系统](../../../02-玩法设计/资源系统.md)：沿用事件触发、费用修正与额外法力槽，不引入直接回复当前法力。

### 共用规则

1. 开局从选手牌读取初始／基础最大生命，不进入抽牌堆，不支付打出费用；不占用第二阵列4个单位格。选手没有普通攻击、反击、移动能力。
2. 恢复生命只增加当前生命，不改变最大生命，且不超过当前最大生命；“获得+1生命值”则同时提高当前生命和最大生命，属于成长而非治疗，不触发治疗监听。生命降至0或以下立即进入败北判定，不依靠后续治疗救回；双方同时归零的裁定沿用项目后续统一规则。
3. “每回合一次”默认只在我方回合触发，次数在我方回合开始重置；“敌方回合中，每回合一次”仅在敌方回合触发并重置。若双方都可触发则写“双方回合中，每回合一次”。卡面不重复默认回合归属。
4. 选手不属于单位，仅指定妖怪的腐化、封除、回手不作用于选手；能力按整局存在估值，不套用妖怪预计存活2回合的系数。
5. 未写次数限制的持续监听按每次合格事件触发。例如林照的攻击后治疗不限制首次攻击；其他明写“每回合一次”的能力在本回合首次完整满足条件时触发。
6. 自伤只统计我方造成的实际正数伤害，不统计敌方伤害、降低最大生命或被完全抵消的伤害；致死伤害先判负。随机对象不存在时不触发能力。
7. 抽牌遵守现有手牌上限且属于额外抽牌。抽牌后置底不等于净抽牌，但仍会产生抽牌事件；满手牌也不会跳过后续置底。
8. 费用修正在支付前处理，只对指定的该次使用生效；不退费、不积存到下回合。最低为1限制该选手的减费贡献，不阻止其他牌合法减到0，亦不把已经为0的牌提高到1。
9. 所有人物、称号与经历继续为C3新增设定；人物职业不强制绑定赞助商。稀有度不作为战斗力分档。

## 三、卡牌详案

### P_CYS_001 林照·破局新秀

- **出身**：曜心城区；`AREA_CHENGYAO_CORE`。
- **人物**：24岁，在交易中心附近的骑楼街区长大。白天整理赛事资料，晚上参加公开挑战，习惯先拆掉对方的关键站位再争取镜头。
- **生命**：30。
- **能力「战后整备」**：友方妖怪攻击后，若存活，为其恢复1点生命
- **构筑与联动**：日巡犬、烬甲魃等攻击后存活即可恢复；攻击敌方妖怪、选手或合法设备均可触发。满生命时不产生实际恢复，攻击仍需支付法力。
- **强度与反制**：每次合格攻击均恢复1，同回合多只妖怪可以分别受益；整体收益依赖存活的攻击妖怪数量。对方可集中击杀、扼制或限制场面。本版沿用30血测试值；解除首次限制后应重测多妖怪进攻的累计治疗，不能沿用旧版单次收益评估。
- **卡图**：午后的骑楼步道，浅色短外套、卷起的赛事记录纸；远处是遮阴广场与竞技场入口。
- **风味**：“先把这一手下好，再想谁会记住我。”

### P_CYS_002 许闻·牌局研究员

- **出身**：曜心城区；`AREA_CHENGYAO_CORE`。
- **人物**：31岁，生长于核心城区普通住区，为社区队做对局分析。她相信阵容互补比一味追逐明星妖怪更可靠。
- **生命**：29。
- **能力「双线复盘」**：每回合一次，我方派遣原始费用为2或3的妖怪后，使其获得+1生命值
- **构筑与联动**：2费锻金咚由1/2成长为1/3，3费焰舞沙魈由3/3成长为3/4。使用现有派遣、原始费用判断和生命成长机制，不要求额外派遣另一只妖怪。
- **强度与反制**：每回合只强化一个符合费用条件的派遣妖怪；1费铺场和高费终结者不受益，召唤也不触发。+1生命值是当前生命与最大生命各+1，不是恢复；增益可被腐化移除。29血暂保留作为稳定成长能力的测试值。
- **卡图**：林荫广场的公共桌旁，便携回放板、铅笔和两叠训练卡；穿日常衬衣而非统一队服。
- **风味**：“好阵容，应该有人补上另一个人的空当。”

### P_CYS_003 陆竞·赤轨试训生

- **出身**：赤轨新城；`AREA_REDRAIL_NEW_CITY`。
- **人物**：20岁，在轨道站旁的住区长大，现参加赤轨俱乐部试训。敢争先手，但坚持记下每次抢攻的实际代价。
- **生命**：29。
- **能力「顶住这一拍」**：每回合一次，己方选手受到我方造成的伤害后，使一个随机友方妖怪获得+1攻击力，持续至回合结束
- **构筑与联动**：锻金咚或双面魍触发后强化仍能攻击的妖怪；与焰舞沙魈、裂炉吼共享自伤事件。能力本身不造成自伤。
- **强度与反制**：相较30血基准减少1点生命，随机结果仍可能落到新派遣或已行动的妖怪；临时攻击无法保证转化为伤害。生命增长至29使自伤更安全，必须连同自伤组件整体测试，不能只看这1点生命差。
- **卡图**：高架下开放球场边，训练背心外罩薄外套，腕上是手写训练记录；背景保留绿道与雨棚市集。
- **风味**：“抢半拍可以，账要自己认。”

### P_CYS_004 程蓄·储能调试员

- **出身**：赤轨新城；`AREA_REDRAIL_NEW_CITY`。
- **人物**：34岁，本地成长的青年技术人员，工作是储能设备调试，业余参加企业间公开赛。习惯把优势留给下一道工序。
- **生命**：28。
- **能力「余量安排」**：每回合一次，额外获得法力槽后，本回合打出的下一张原始费用不低于3的妖怪牌获得费用-1，最低为1
- **构筑与联动**：需求响应在我方回合开始额外增槽后，可接3费以上妖怪；储能回充需先付费用，再安排派遣。常规回合增长不触发。
- **强度与反制**：每回合至多登记一份减费，使用后不能因再次增槽刷新，未用奖励回合末失效；不减少法术费用。28血承担持续节奏能力的代价，增槽触发门槛保留。赞助牌仍按现有渠道获取。
- **卡图**：车站储能检修通道，工装、绝缘工具袋、带遮阳的检修窗；神情专注，设施没有对外射出的光束。
- **风味**：“峰值之后，才知道准备够不够。”

### P_CYS_005 唐映·街场主持人

- **出身**：镜幕商环；`AREA_MIRROR_COMMERCIAL_RING`。
- **人物**：27岁，生长于商环居民街，主持小型挑战赛，也亲自报名。她擅长让观众看懂一套连续操作。
- **生命**：27。
- **能力「接上好戏」**：我方打出本回合第3张牌后，若本回合派遣过妖怪且手牌不多于2张，抽1张牌
- **构筑与联动**：低费妖怪配合日轮高悬或铁路服务牌形成三牌连打。第3张为妖怪时，其派遣完成后算作满足条件；手牌数在第3张牌及其引发的效果结算后检查。
- **强度与反制**：保留真正的净补牌，但要求连打、派遣和低手牌同时满足，以27血承担当回合续牌的强节奏。第4张及之后不补发；前3张没有派遣妖怪也不补发。对方可压血、迫使其花法力攻击或提前耗掉关键妖怪。
- **卡图**：有树荫的步行街挑战台，手持小型麦克风，衣着鲜明但日常；显示屏只存在于获批场馆节点。
- **风味**：“别急着鼓掌，下一手接得上才漂亮。”

### P_CYS_006 ==罗序·转播编排师==

- **出身**：镜幕商环；`AREA_MIRROR_COMMERCIAL_RING`。
- **人物**：36岁，在老影院附近长大，为赛事转播编排流程，轮休时打业余联赛。她的牌局像节目单，每一步都为下一步留位置。
- **生命**：28。
- **能力「顺势接场」**：若我方本回合打出的第1张牌是妖怪，第2张牌为原始费用不低于2的法术时，该法术获得费用-1，最低为1
- **构筑与联动**：先派遣再接烈日当空，或搭配副地区功能法术。不能给御术、设备减费，也不为第3张之后的法术补发折扣。
- **强度与反制**：每回合第2张的位置天然只出现一次，不需要额外计次。先妖怪后法术与先预测天气再派遣的顺序存在取舍；减费按支付前的实际费用处理，不产生退款。持续每回合省费因此使用28血。
- **卡图**：剧场侧门外的遮阴休息区，耳机挂在颈间，纸质流程单与卡套并置。
- **风味**：“时机排对了，普通的一手也能有分量。”

### ==P_CYS_007 何勤·燃栖维护员==

- **出身**：燃栖城郊带；`AREA_RANQI_OUTSKIRTS`。
- **人物**：43岁，住在维护站附近的老社区，长期参加邻里联赛。习惯用常见妖怪组成扎实阵容，不把淘汰损耗当成表演。
- **生命**：30。
- **能力「收工点验」**：回合结束时，若本回合有原始费用不高于2的友方妖怪被消灭，为己方选手恢复1点生命
- **构筑与联动**：青铜叶鳅等低费妖怪主动交换，配合自伤卡缓慢补回生命。敌方回合的死亡不带入下个我方回合，满生命时没有实际恢复。
- **强度与反制**：每个我方回合仅恢复1点，依赖低费妖怪阵亡；不减免伤害，不救回致死自伤。每次从8恢复到9都可能改变归焰凰之后的回收条件；30血下要重点观察控制局中累计治疗是否压低快攻胜率。
- **卡图**：傍晚的维护站门口，旧工装、保温水壶、清点工具的折叠桌，背景是住区与低丘绿地。
- **风味**：“今天少损一点，明天就多撑一手。”

### P_CYS_008 苏堤·雨洪巡查员

- **出身**：燃栖城郊带；`AREA_RANQI_OUTSKIRTS`。
- **人物**：29岁，在澄青河上游一带长大，负责日常雨洪巡查，休息时参加开放赛。她重视撤去障碍、把队伍送到需要的位置。
- **生命**：31。
- **能力「沿线照应」**：每回合一次，受伤的友方妖怪移动后，为其恢复2点生命
- **构筑与联动**：受伤的日巡犬、铁芯蟾前移时恢复；自然移动与进路开放等效果移动均可触发。先发直接派遣不算移动。
- **强度与反制**：只治疗、不提高最大生命、不刷新行动，且妖怪必须先存活、受伤、能够合法前移。移动通常消耗法力并使其本回合不能攻击；触发门槛高，给31血补偿。与RBC叠加须记录实际有效治疗，不能把满血溢出算作收益。
- **卡图**：阵雨后的低丘步道、湿地边缘，轻便雨衣收在腰侧，手拿巡查地图；与城市晴天场景区分。
- **风味**：“路通了，也得有人走得过去。”

### P_CYS_009 方衡·公园陪练员

- **出身**：曜南竞技公园；`AREA_YAONAN_ARENA_PARK`。
- **人物**：38岁，在园区生活服务片区长大，组织市民陪练。教新人先把妖怪留在场上，再学习复杂连招。
- **生命**：33。
- **能力**：无特殊能力
- **构筑与联动**：作为本批无能力对照选手，适合新手、通用构筑与需要额外生存空间的牌组。30血带能力的选手需要靠实际收益弥补3点生命差。
- **强度与反制**：相较30血基准多3点初始和最大生命，没有额外卡差、减费或场面修正。高生命不保证更强：遇到资源型对局可能缺少持续收益；用于检测其他选手是否在多数环境中成为明显更好的通用选择。
- **卡图**：上午的公共练习场，宽松运动服、旧哨子、折叠记分板；周围是慢行环线和树荫。
- **风味**：“别急着赢，先让下一回合还有牌可打。”

### P_CYS_010 季晴·露天赛选手

- **出身**：曜南竞技公园；`AREA_YAONAN_ARENA_PARK`。
- **人物**：22岁，在园区生活片区成长，常打露天公开赛，擅长观察天气与场面共同形成的进攻窗口。
- **生命**：29。
- **能力「晴场抢拍」**：每回合一次，友方妖怪攻击时，若是艳阳天，使其造成的伤害+1
- **构筑与联动**：日轮高悬预测的艳阳天实际生效后，安排最合适的妖怪先攻击。移除原火元素限定，天气决定进攻窗口，金、水或其他元素妖怪也能受益。
- **强度与反制**：可以强化一次合法的对选手攻击，但不绕过前排保护、掩护或攻击费用。没有艳阳天则无收益；对方改天气、扼制或清理攻击者均可应对。29血承担持续抢血能力，普通攻击之外的伤害不获得加成。
- **卡图**：明亮的室外赛场边，遮阳帽、毛巾和轻便赛事服；画面有遮阴棚与饮水设施。
- **风味**：“晴天不是优势，准备好的人才是。”

### P_CYS_011 叶岑·红谷观察员

- **出身**：红谷生态保护区；地方ID暂未登记。
- **人物**：26岁，在保护区日常生活与管理服务范围内长大，记录普通妖怪的活动时段。参加比赛是为比较自己观察到的行为规律，而非追逐罕见妖怪传闻。
- **生命**：30。
- **能力「换候笔记」**：每回合一次，我方预测天气后，抽1张牌，然后将1张手牌置于卡组底
- **构筑与联动**：日轮高悬、烈日当空可触发，抽后选择把较差手牌置底，改善后续牌序。采用已有抽牌后置底流程，无需新增牌库顶排序界面；手牌数量通常不变。
- **强度与反制**：不直接获得净卡差，但抽牌仍能触发额外抽牌监听，必须纳入联动估值。只有我方成功登记预测才触发；天气自然变化、清除天气或直接改变天气不算预测。满手牌时抽到的牌仍按现行上限弃置，再执行置底，可能损失手牌。
- **卡图**：保护区观察步道，素色户外衬衫、小望远镜与纸笔；远景为自然植被，不画未确认的地标或稀有大妖。
- **风味**：“同一条路，天气一换，就有新的答案。”

### P_CYS_012 顾栎·红谷巡护员

- **出身**：红谷生态保护区；地方ID暂未登记。
- **人物**：41岁，自幼在保护区生活服务范围成长，从事日常巡护，也参加本地业余赛。认为好指挥应当关注受伤的伙伴，而不是只看攻击数字。
- **生命**：30。
- **能力「缓一口气」**：敌方回合中，每回合一次，友方妖怪受到伤害后，若存活，为其恢复1点生命
- **构筑与联动**：回应敌方回合的攻击、法术、反应及其他伤害，让存活的妖怪多支撑一次交换。与林照区分为敌方回合防护，不在我方回合主动受伤时提供治疗。
- **强度与反制**：由每回合末随机恢复2改为敌方回合受伤后恢复1，治疗量减小但时点更及时；不能救回致死伤害。对方可用小伤害消耗当回合机会，再打主要伤害；一次群体伤害也只治疗首个符合条件的存活妖怪。
- **卡图**：薄云天气下的观察小径，旧外套、急救包与磨损的卡套；保留安静的自然空间。
- **风味**：“赢下这一场，也得顾得上下一程。”

## 四、结算边界

### 本批生命效果分类

| 选手 | 行为 | 最大生命是否改变 |
|---|---|---|
| 林照、何勤、苏堤、顾栎 | 恢复生命；只能补回缺失生命 | 否 |
| 许闻 | 妖怪获得+1生命值；当前生命和最大生命各+1 | 是 |
| 方衡 | 开局33点生命，无成长或治疗能力 | 开局设定为33，之后不由自身能力改变 |

例如许闻让2/3生命的妖怪获得+1生命值后为3/4，依然受伤；林照让2/3生命的妖怪恢复1后为3/3，变为满生命。两者不是同一种收益，不互换结算或治疗监听。

### 攻击、受伤与治疗

- **林照**：攻击目标不限定种类，每次合法攻击及死亡处理后，检查发起攻击的友方妖怪是否存活，再为其恢复1。没有本回合首次限制；前一只死亡不影响后一只攻击后的治疗。反击不算发起攻击，满生命时恢复量为0。
- **季晴**：我方回合首次在艳阳天下发起的合法妖怪攻击，造成的伤害+1；此前非艳阳天的攻击不占机会。加成绑定这次攻击，合并到原攻击伤害中结算，不提高攻击力、不新增独立伤害事件，不提高派遣、亡语或其他效果伤害；反击不触发。该次攻击结束后修正失效，未造成伤害也不转移给后续攻击。
- **陆竞**：伤害实际结算且选手存活后，再选择随机友方妖怪。攻击中搏命熊的自伤可以触发，但不承诺随机增益一定强化该次攻击；收益取决于实际目标和攻击队列。其临时+1不能被重复自伤叠加。
- **顾栎**：仅在敌方回合监听。首个实际受到正数伤害且在死亡处理后仍存活的友方妖怪触发，触发标记须在治疗前占用。被伤害消灭的妖怪不消耗机会，后续存活者仍可触发。群体伤害按现有队列，只治疗首个合格对象；不是每个对象各恢复1。
- **苏堤**：合法前移后检查妖怪仍在场且受伤，再恢复。满生命妖怪移动不占机会；若前移同时引发其他效果，按队列读取当时生命。不能逆向移动，也不增加攻击资格。
- **何勤**：只统计本我方回合内被消灭的低费友方妖怪，费用按原始费用；召唤物与克隆属于妖怪，符合费用则正常计入，设备摧毁不计。低费妖怪死亡再多也只在回合末恢复1，满血则实际恢复0。

### 派遣、牌序与资源

- **许闻**：每回合第一次派遣原始费用为2或3的妖怪后，向该妖怪发放+1生命值。原始费用不受手牌减费影响；派遣其他费用妖怪不消耗机会。召唤不触发，克隆牌从手牌正常派遣则按其原始费用判断。
- **派遣后增益**：先完整结算该次派遣及其效果，再向本次妖怪发放生命成长。若本次妖怪已离场，不发奖励、不消耗本回合成功触发次数，也不把增益转给其他妖怪。无需记录前一次派遣的元素或比较两只妖怪。
- **出牌计序**：妖怪派遣、法术使用、御术激活及设备部署计数；召唤、抽牌、攻击、移动和御术自动触发不计。每个我方回合重置。
- **唐映**：第3张牌及其引发的效果全部结算后，再读取手牌是否不多于2张；先标记处理完该次序号，再抽牌，避免抽牌监听回入重复发奖。第3张未满足条件，本回合后续出牌不能补发。
- **程蓄**：我方回合第一次额外增槽登记减费，一次增加多个槽算一次。登记后同回合不重复登记，即使用掉折扣也不刷新；不用则回合末失效。回合开始额外增槽可以登记，正常增长与敌方回合增槽不登记。
- **程蓄／罗序减费**：先算其他卡牌修正，再应用本选手的-1；仅当剩余费用至少2时减1，否则贡献0。例如其他来源将3费减到1，该选手不再减；其他来源已经减到0，仍为0。符合条件的该次使用后，该份修正结束，不能转移给下一张牌。
- **叶岑**：我方首次成功登记天气预测后触发，重复预测同一种天气也算，预测来源牌未成功生效则不算。无需等待天气改变；直接改变天气和自然变化都不触发。抽牌后从当前手牌选择1张置底，能够选择原本就在手中的牌。卡组无牌时按既有抽牌规则处理，仍从现有手牌执行置底；手牌也空时跳过置底。

## 五、强度依据与血量调整

### 与现有卡池的对应

| 现行锚点 | v0.3的处理 |
|---|---|
| 锻金咚：2费1/2，自伤1抽1，艳阳天抽2 | 许闻使用符合费用条件的派遣成长；唐映的净补牌要求第3张、派遣、低手牌并以27血承载；叶岑改为抽后置底。 |
| 裂炉吼、焰舞沙魈：自伤事件提供成长或临时攻击 | 陆竞保留小幅随机临时攻击，不增加自动自伤和永久叠加。 |
| 日巡犬：受伤后回合末恢复1／艳阳天2 | 林照在每次攻击后恢复1，顾栎在敌方回合受伤后每回合恢复1次；苏堤恢复2但要求合法前移。 |
| 峰谷调度、CTCS-3：支付卡牌成本后提供减费 | 程蓄、罗序每回合至多提供一次-1，限制对象、顺序与本能力的减费下限，使用28血。 |
| RBC：移动后+1生命值并恢复1 | 苏堤只有实际治疗，没有最大生命成长；保留移动成本和行动限制。 |
| 归焰凰：生命不大于8触发亡语克隆回收 | 8仍是绝对生命阈值，不随初始生命等比例提高。以新血量重测启动时机。 |

旧数值表的“本回合获得法力”等条目不作为依据，仍以更新后的资源规则为准。选手不消耗抽到它的概率、手牌或打出费用，因此持续收益不能直接等价成一张同效果妖怪。

### 生命不是能力的精确兑换价格

- **33生命**：方衡无能力，提供清楚的对照。
- **31生命**：苏堤的受伤前移条件较难持续满足，给予少量生命补偿。
- **30生命**：主动交换、防护、条件选手治疗或天气整理作为中点。
- **29生命**：永久生命成长、临时进攻、天气抢血具备更高转化潜力。
- **28生命**：可重复减费更容易转为额外出牌节奏。
- **27生命**：唐映具备当回合净补牌能力，门槛之外再承担较低生存空间。

这是初始测试排序，不是固定“1血等于某个效果”的换算。持续能力在长局中会积累更多收益，33血无能力应是对照，而不是要求它和每张专精选手在所有构筑中相同胜率。

相较原20血，27—33血增加35%—65%的初始生命。攻击力、直伤与费用不变时，对局通常会变长；不能把这次改动当成只影响人物的小数值修订。需要重点验证三点：

1. 常驻治疗与新增生命是否共同压低快攻的获胜机会；
2. 更长对局是否放大永久成长、额外抽牌与减费的累计收益；
3. 自伤安全空间变大，而归焰凰8血触发更晚，两种相反影响如何改变澄曜自伤构筑。

## 六、接入检查与首测顺序

本次完成设计文档与规则文字调整，尚未修改运行时代码或证明实战平衡。

| 场景 | 预期 |
|---|---|
| 分别选择唐映、方衡开局 | 初始及基础最大生命分别为27、33；不能回落到固定20或30。 |
| 连续多个我方回合触发陆竞 | 每个回合都能重新触发一次，不会在第4次后失效。 |
| 林照第1只攻击者死亡、第2只存活且受伤 | 第2只正常恢复1；前一次攻击不消耗后续机会。 |
| 林照的受伤妖怪分别攻击妖怪、选手或合法设备后存活 | 均恢复1；不限定目标类别，也不限定本回合首次。 |
| 许闻先派遣1费妖怪，再派遣2费、3费妖怪 | 只强化2费妖怪一次，元素无关；下回合可重新触发。 |
| 许闻派遣减至1费的原始3费妖怪／通过效果召唤3费妖怪 | 派遣符合条件，召唤不触发。 |
| 程蓄同回合多次增槽 | 只登记一份减费，使用后不刷新；新回合可重新登记。 |
| 罗序与其他减费叠加 | 只减第2张合格法术，贡献不会把1降至0，也不会提高已有0费。 |
| 唐映第3张结算完有2张／3张手牌 | 前者满足其他条件时抽1，后者不抽；之后手牌减少不补发。 |
| 叶岑预测晴天、直接改晴天、自然转晴 | 仅预测触发；抽后置底一般不改变手牌数。 |
| 顾栎在我方回合受伤／敌方回合致死受伤 | 均不治疗；敌方回合后续非致死伤害仍有机会。 |
| 顾栎在敌方回合受群体、多段伤害 | 每个敌方回合只治疗首个合格的存活妖怪一次。 |
| 选手1生命受到1点自伤 | 立即败北，任何后续恢复都不能救回。 |
| 选手当前生命9、最大生命27或33，归焰凰死亡 | 都不满足不大于8；不按最大生命比例重算阈值。 |

先测试方衡、林照、苏堤建立高生命白板与场面恢复对照，再测试许闻、季晴、顾栎；最后集中测试唐映、程蓄、罗序以及陆竞与自伤体系、叶岑与额外抽牌监听的联动。

采用相同29张构筑、只替换选手的配对对局，并为专精选手补测适配构筑；交换先后手，涵盖快攻、中速和控制。记录胜率、对局回合数、首次与每回合触发率、实际治疗、净抽牌、整理牌次数、实际减费、斩杀回合和8血阈值到达回合。没有对战数据前，不宣称27—33血与这批能力已经等强。
