# 概率公式

## 1. 攻击触发公式

```text
攻击反应概率 = 基础概率 + 攻击者当前攻击力 × 6% + 天气修正
```

默认限制：

```text
最低 15%
最高 80%
```

如果天气写明“必定触发”：

```text
概率 = 100%
```

如果天气写明“禁止触发”：

```text
概率 = 0%
```

示例：

```text
3攻火单位攻击木单位
普通天气：15% + 3 × 6% = 43%
艳阳天：100%
雨天：0%
```

---

## 2. 法术触发公式

法术概率只适用于**造成对应元素伤害的法术牌**。

```text
法术反应概率 = 法术基础概率 + 法术伤害值 × 8% + 天气修正
```

默认限制：

```text
最低 25%
最高 90%
```

示例：

```text
2点火焰伤害法术命中木单位
普通天气：55% + 2 × 8% = 71%
艳阳天：100%
雨天：0%
```

你的现有效果系统已经是 `EffectActionSO -> IEffectAction`，后续可以新增 `ElementalDamageActionSO`，在原 `DamageActionSO` 基础上扩展元素、概率和是否允许反应字段。

## 反应状态分类与移除

反应状态指元素反应触发后，留在对象上的状态。例如火元素A攻击木元素B触发点燃，B身上的点燃就是反应状态。

| 分类 | 当前示例 | 移除反应状态是否移除 |
|---|---|---|
| 反应状态 | 点燃、熄灭、淤塞、熔蚀、根裂 | 是 |
| 其他负面状态或效果 | 扼制、腐化、中毒 | 否 |
| 正面状态或增益 | 护盾、强化、吸收带来的永久成长 | 否 |
| 即时反应结算 | 劈斩的本次穿透、吸收的即时治疗 | 否，不是残留状态 |

- “移除其反应状态”移除该目标当前全部反应状态，不需要选择顺序或编辑状态列表。没有可移除状态时，卡牌的其他效果照常结算。
- 移除淤塞恢复被其暂时封锁的在场效果；不会恢复被腐化移除的能力。
- 移除点燃只终止后续点燃伤害，不返还已扣生命；移除熔蚀只解除尚未消耗的下次攻击削弱，不返还已移除的护甲。
- 同名状态按其类型归类，卡牌直接施加“点燃”仍属于点燃反应状态，不要求记录它是否真的由一次反应生成。
- 根裂的下次受伤加成在消耗前属于可移除的反应状态。

“下一次元素伤害+X”按《触发效果规则》的伤害队列逐目标结算，仅首个符合元素条件的条目获得加成；法术本身不因此获得元素身份。

## 反应条件的来源与可达性（2026-09-06）

- 回手、抽牌、治疗、消灭、扼制、腐化、召唤和改变天气本身不造成元素伤害，不会仅凭法术设计表中的地区元素触发反应。
- 法术先明确造成对应元素伤害，再按伤害与目标元素判断反应。例：“对其造成1点木元素伤害。若以此触发「根裂」，……”；没有实际伤害结算时，不获得反应奖励。
- “若以此触发”只检查所承接的那段伤害，在一次效果中最多发放一次该条件奖励；奖励伤害不能再次回到同一条件自我递归。
- 妖怪的独立反应奖励在无其他可能主体时写“触发「淤塞」后，……”；前文出现其他妖怪或可能混淆反应主体时，写“本妖怪触发「淤塞」后，……”。“反应目标”指本次反应实际作用的对象，自动沿用事件对象，不重新手动选择。
- 检查反应与妖怪元素是否对应：火→点燃／熔蚀；水→熄灭；木→吸收／根裂；土→淤塞；金→劈斩。其余目标、天气及伤害条件仍须满足本文件反应表。
- 不把没有伤害的派遣效果、召唤或治疗写成反应来源。妖怪以后通过攻击触发的奖励，另写为在场触发，不混入这些一次性效果的条件分支。
