#标准回合流程设计
## 一、核心资源规则

### 法力规则

```
每位玩家拥有法力。法力用于：打出卡牌、妖怪攻击、妖怪移动。每回合开始时：1. 法力上限 +1
2. 法力恢复至当前上限
3. 正常回合增长最高到 12；效果额外获得法力槽可突破此值
```

推荐数值：

```
对局开始法力上限：0（第一回合正常增长后为1）
正常回合增长上限：12（效果额外获得法力槽可突破）
每回合增长：+1
```

这样前期不会太慢，中后期也能同时完成“出牌 + 攻击 + 移动”。

---

## 二、回合开始阶段

### 1. 进入回合

选手初始及基础最大生命由开局所选选手牌决定。对局中每次伤害或生命变更后都检查选手生命；降至0或以下立即进入败北判定，不等待本文件列出的回合末复查，后续治疗不能救回。详见《胜负条件》。

```
当前行动方成为本回合的主动玩家。
```

系统处理：

```
触发：回合开始
触发：本方回合开始
触发：敌方回合开始
资源事件先登记，按下一节的增槽、补满、扣减顺序结算，不能在补满前实际扣减待干扰的法力。
```

可用于结算：

```
回合开始时，获得护盾
回合开始时，天气造成伤害
回合开始时，恢复生命
回合开始时，某些持续效果倒计时减少
```

---

### 2. 刷新法力

```
行动方法力槽数不足12时，正常增加1点法力槽；达到或超过12时不再正常增槽，也不减少现有槽数。先处理本回合开始的额外增槽，再将当前法力恢复至最大法力；最后结算登记在本回合开始的失去法力值效果，最低为0。
```

示例：

```
额外获得法力槽只提高最大法力，不补充当前法力。例如1/3额外获得1点法力槽后为1/4；我方下回合开始正常增槽并补满后为5/5。12/12额外获得1点法力槽后为12/13，下回合不再正常增槽，补满后为13/13。
```

---

### 3. 刷新妖怪状态

行动方场上所有妖怪刷新行动状态：

```
所有可行动妖怪重置为“未攻击”
所有可移动妖怪重置为“未移动”
移除“直到本回合开始”的临时效果更新持续回合类 Buff / Debuff
```

召唤疲劳：

```
上回合之前上场的妖怪，本回合可以攻击。本回合刚上场的妖怪，默认不能攻击。拥有“疾袭”的妖怪，登场当回合可以攻击。
```

---

### 4. 抽牌

```
行动方从牌库抽1张牌加入手牌。这是正常规则抽牌；效果带来的抽牌按“额外抽牌”记录。
```

限制：

```
手牌上限：10超过上限时，新抽到的牌被弃置，不进入场外牌堆。
```


---

## 三、主行动阶段

主行动阶段是玩家自由操作阶段。

玩家可以以任意顺序执行以下行动：

```
1. 打出手牌
2. 使用法术牌
3. 妖怪攻击
4. 妖怪从第二阵列移动至第一阵列
5. 结束回合
```

只要满足条件，行动可以重复执行，直到玩家选择结束回合。

---

# 四、主行动阶段具体动作

## 动作 A：打出卡牌

### 1. 打出妖怪牌

条件：

```
玩家拥有足够法力目标行至少有一个空位置时卡牌满足放置限制
```

放置限制：

```
任意位置：可以放前排或后排仅前排：只能放前排仅后排：只能放后排
```

流程：

```
玩家选择手牌中的妖怪牌选择合法位置支付卡牌费用妖怪进入对应槽位
触发：妖怪登场
触发：部署效果
```

部署效果

```
若妖怪带有明确需要指向目标的部署效果，例如：对一个花费不超过2点法力的妖怪造成两点伤害；此时若存在符合条件的目标，只指定一个目标；若不存在则仍正常派遣，跳过无合法对象的效果（此规则仅适用于妖怪牌）
```
示例：

```
玩家拥有 6 法力。打出 3 费妖怪到前排。剩余 3 法力。本妖怪本回合默认不能攻击，除非拥有“疾袭”。
```

---

### 2. 打出法术牌

条件：

```
玩家拥有足够法力若法术需要明确的指向目标，则必须选择合法目标
```

流程：

```
指向性法术：选牌 → 指定一个合法目标 → 支付费用并打出 → 结算效果。
非指向性法术：选牌 → 支付费用并打出 → 自动结算。
随机及相邻对象自动确定，不再选择第二个目标。结算后进入弃用状态，记录出牌与结算事件。
```

---

### 3. 打出持续类卡牌


```
玩家支付费用选择目标或区域卡牌进入对应区域持续生效或立即结算
```

比如天气：

```
带天气效果的牌结算后，按文本预测天气、清除天气或立即改变天气
触发：天气改变
```

---

## 动作 B：妖怪攻击

### 1. 攻击基础规则

```
每个妖怪每回合最多攻击 1 次。攻击需要支付法力。普通攻击默认消耗 1 法力。部分妖怪攻击消耗 2 或更多法力。攻击后，本妖怪标记为“已攻击”。
```

推荐默认：

```
普通妖怪：攻击消耗 1
重型妖怪：攻击消耗 2
特殊妖怪：根据卡牌配置决定
```

---

### 2. 前后排攻击规则

现在的规则可以整理为：

```
前排妖怪：可以攻击敌方前排 可以攻击敌方后排 可以攻击敌方选手
后排妖怪：只能攻击敌方前排当敌方前排没有妖怪时，默认不能攻击敌方选手和敌方后排
```

也可以加关键词突破：

```
远射：后排妖怪可以攻击敌方后排
狙击：可以无视前排攻击后排
飞行：可以攻击任意敌方妖怪
掩护：敌方必须优先攻击拥有掩护的妖怪
```

---

### 3. 攻击流程

```
玩家选择一个己方可攻击妖怪系统检查本妖怪是否未攻击、未被控制、未被冻结
玩家选择合法敌方目标系统检查目标是否合法
支付攻击法力
播放攻击动画
双方结算战斗伤害
死亡妖怪进入死亡结算
攻击者标记为已攻击
触发：攻击后
```

战斗伤害建议：

```
攻击者对目标造成等同于自身攻击力的伤害。若目标也是妖怪，目标同时对攻击者造成反击伤害。若目标是选手，选手不反击，除非有特殊效果。
```

---

## 动作 C：妖怪移动

### 1. 移动规则

```
妖怪只能从第二阵列移动至第一阵列的合法空位，不存在同排移动或反向移动。移动消耗1点法力，每个妖怪每回合最多移动1次；移动后默认不能攻击。
```

这个“移动后不能攻击”很重要，否则移动和攻击组合会太强。

可以加关键词：

```
机动：移动后仍可攻击
迟缓：不能移动
冲锋：从后排移动到前排后，可以立即攻击
守备：不能移动，但受到伤害降低
```

---

### 2. 移动流程

```
玩家选择第二阵列的友方妖怪，选择第一阵列的合法空槽位，系统检查本妖怪是否可以移动系统检查目标槽位是否合法支付 1 法力妖怪移动到目标槽位标记为“已移动”若无特殊关键词，标记为“本回合不能攻击”触发：妖怪移动后
```

---

## 在场效果的结算

当前不提供妖怪主动技能按钮或付费发动流程。在场效果按明确事件自动触发；是否有抉择、是否指定目标及其次数，按《卡牌使用与目标选择》执行。

---

# 五、结束回合阶段

当玩家点击结束回合后，进入回合结束流程。

## 1. 锁定玩家操作

```
禁止继续出牌
禁止继续攻击
禁止继续移动
禁止继续拖拽目标
```

---

## 2. 结算回合结束效果

```
触发：回合结束触发：本方回合结束触发：敌方回合结束
```

可用于：

```
回合结束时造成伤害回合结束时恢复生命回合结束时召唤妖怪回合结束时弃牌回合结束时天气轮次结算
```

---

## 3. 清理临时状态

```
移除“直到回合结束”的 Buff / Debuff移除临时攻击力加成移除临时护盾清理本回合标记
```

例如：

```
本回合攻击力 +2本回合不能攻击本回合获得远射本回合移动费用 -1
```

---

## 4. 检查胜负

```
若任意玩家选手生命 <= 0，进入胜负结算。若双方选手同时 <= 0，判定平局或按规则决定胜负。
```

---

## 5. 切换行动方

```
当前玩家回合结束。切换到另一位玩家。进入下一位玩家的回合开始阶段。
```

## 召唤与克隆入场补充

通过效果入场使用“召唤”，不触发派遣。默认放入控制者第二阵列最右边的合法空位，满员则无法召唤；只有明确指定第一阵列时才放入该阵列最右边的合法空位。召唤位置不随机，不跨阵列寻找替代空位。召唤多个时依次处理。复制自身入场统一写“召唤一张本妖怪的克隆”。

## 设备部署与效果支付补充

行动阶段可以支付费用，将设备部署到我方第二阵列一个合法空位。部署计入出牌顺序，不计为妖怪派遣或召唤。设备不可攻击或移动；受到合法伤害时扣减防御力，降至0被摧毁。详细目标与阵列规则见《设备牌设计》。

出牌顺序及条件减费统一为“获得费用±X”，在支付前生效，不能支付后补算。机械造物仍按妖怪行动规则处理，“机械”只限制法术牌的妖怪目标指定。

群体伤害按队列逐目标结算，“下一次伤害+X/-X”只被首个符合条件的条目消耗，后续条目不重复获益。
