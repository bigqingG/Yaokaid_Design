# 关键词与词条

## 战斗关键词
| 关键词 | 原型名   | 效果                                                 |
| --- | ----- | -------------------------------------------------- |
| 疾袭  | 突击    | 单位上场当回合可以行动，攻击或移动皆可。                               |
| 亡语  | 终声    | 单位死亡并进入场外牌堆时触发效果。                                  |
| 掩护  | 嘲讽    | 敌方普通攻击必须优先选择拥有掩护的合法目标；第一阵列存在敌方掩护单位时，不能普通攻击其第二阵列单位。 |
| 护甲X | 装甲X   | 抵挡X点战斗伤害；未写持续时间时默认为持续存在，直到被伤害或效果移除。                |
| 蜕变  | 进化    | 达成指定条件后替换为另一形态；形态变化不视为派遣。                          |
| 扼制  | 压制    | 被扼制单位的下个回合无法攻击；不可叠加，只刷新持续。                         |
| 腐化  | 沉默/净化 | 移除一个单位的所有增益、词条和在场效果。                               |
| 先发  | ----- | 可直接派遣到前排                                           |

### 机械关键词

- **机械**：不能被法术牌指定为妖怪目标。机械造物自带此关键词，仍属于妖怪。
- **妖怪目标**：法术效果明确要求选择“妖怪”时所指定的目标。泛指目标、无指定的群体效果及非法术效果不因机械而失效。

## 入场与区域词条
| 术语   | 规则                                      |
| ---- | --------------------------------------- |
| 打出   | 玩家从手牌使用一张牌并支付费用。                        |
| 派遣   | 玩家从手牌打出妖怪并放入战场。派遣会触发“派遣：”效果。            |
| 部署 | 从手牌支付费用放置设备，不属于妖怪派遣或召唤。 |
| 防御力 | 设备承受伤害的数值，受到伤害时扣减，降至0被摧毁；不是护甲或攻击力。 |
| 召唤 | 通过效果使妖怪入场；默认进入第二阵列最右边的合法空位，满员则失败。明确指定第一阵列时，也进入其最右边；不触发派遣效果。 |
| 克隆 | 原对象的副本；生成并入场写“召唤一张本妖怪的克隆”，原对象与克隆分别存在。 |
| 封除   | 将单位移出战场并放入公共封存卡组；封存卡组双方共用，不保留我方/敌方归属。   |
| 征召   | 从公共封存卡组随机抽取一张单位，按召唤规则进入征召者第二阵列最右边的合法空位，满员则无法召唤，并由征召者控制。 |
| 场外牌堆 | 只记录死亡单位；法术结算后不进入场外牌堆。                   |
### 封存卡组补充规则

- 封存卡组是双方共用的公共卡池，不区分原控制者或原拥有者。
- 任意一方封除进去的单位，之后都可能被任意一方征召出来。
- 征召默认随机抽取；如果文本给出费用、类型等筛选条件，则先筛选合法范围，再随机抽取。
- 被征召出的单位由征召者控制，按召唤规则进入征召者战场；它不是“回到原主人手上/场上”。
- 卡牌可以检查公共封存卡组的总数量或是否为空，但不应写“你的封存卡组”“敌方封存卡组”。

## 元素状态
| 状态 | 规则 |
| --- | --- |
| 点燃 | 目标回合结束时受到1点火元素伤害，持续2回合；不叠加，只刷新。 |
| 熄灭 | 目标无法触发火元素反应，持续2回合；不叠加，只刷新。 |
| 吸收 | 即时成长：攻击者永久获得生命上限并治疗等量生命。 |
| 淤塞 | 目标暂时失去自身在场效果，持续2回合；效果结束后恢复。 |
| 劈斩 | 本次战斗伤害无视最多2点护甲。 |
| 熔蚀 | 目标下次攻击伤害-1；若有护甲，先移除1点护甲。 |
| 根裂 | 目标下次受到伤害+1。 |

## 反应状态

反应状态是元素反应留在目标上的状态：点燃、熄灭、淤塞、熔蚀、根裂。移除反应状态不会移除扼制、腐化、中毒等其他负面状态，也不会移除护盾、强化等正面状态。

“移除其反应状态”默认移除全部现存反应状态；没有反应状态时不执行移除，治疗等其他效果仍正常结算。吸收的即时成长与劈斩的本次穿透不是可清除的残留状态。详细分类及例子见《元素系统》。

## 动作与抽牌用语（2026-09-06）

- **扼制**作为动词使用：“扼制一个敌方妖怪”“扼制其”。状态仍按原期限结算，不因措辞调整变为永久能力。
- **消灭**：直接使妖怪死亡，友方与敌方使用同一动作，不设牺牲动作。不是伤害，不触发元素反应；仍结算死亡与亡语。
- **额外抽牌**：正常规则抽牌以外的效果抽牌。生成、回手和检视选牌不属于抽牌；详见《资源系统》。
- **叶灵**：当前唯一固定生成的召唤物名称，基础1/1。母牌写“召唤1个叶灵”；完整属性、附加效果与来源见[子卡牌设计](../03-卡牌设计/子卡牌设计/README.md)。
